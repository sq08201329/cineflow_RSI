# 阶段 0 调研：声音 Agent 闭环（006-sound-agent）

> 每个决策 = 分歧点 → 备选 → 结论 → 依据。规格：[spec.md](spec.md)（含 2026-09-20 澄清两条）。

## 决策 1：落树节奏——生成即评即落树，无外部回流

- **分歧**：声音节点是否需要 promo 式的"投放→外部指标回流→落树"两段节奏？
- **备选**：(a) visual 模式（生成→立即评估→同轮一次性 INSERT）；(b) promo 模式（等外部回流）
- **结论**：**(a) visual 模式**——声音评估信号全部来自自动评估器（四评估器即时可算），
  无平台真值回流
- **依据**：技术方案 §2.2 声音行仅硬规则 + 代理模型；两段式落盘的可变侧
  （`sound_gen_jobs` 运营表）只承载生成中间态，评估完成即冻结入树。

## 决策 2：程序化音频合成的确定性与声学属性注入

- **分歧**：模拟生成器产出什么形态的 wav？
- **备选**：(a) numpy 正弦叠加 + 包络，标准库 wave 写 PCM16；(b) 引第三方合成库
- **结论**：**(a)**——`agents/sound/audio.py`：参数种子 → numpy 波形（基频/谐波/包络/时长
  由参数决定）→ PCM16 wav；声学属性可注入：响度增益、时长、语音事件时间戳、
  "错字"扰动标记（随工件元数据落盘）
- **依据**：规格假设——模拟音频只需声学属性可控，不追求真实音质；numpy + 标准库
  零新增依赖；同参数逐字节复现（SC-002）由固定种子与定点运算保证（004 同款纪律）。

## 决策 3：响度测量算法

- **分歧**：LUFS 怎么测？
- **备选**：(a) 纯 numpy 简化 BS.1770（K 加权近似 + 积分能量，定点输出）；(b) 引 pyloudnorm
- **结论**：**(a) 纯 numpy 简化实现**，输出定点归一（6 位小数）
- **依据**：测量只需确定性与单调正确（合规/违规判定稳定），不需计量级精度；
  pyloudnorm 收益不抵依赖（YAGNI）；实现哈希入评估器版本号，将来换真实库 = 升版本。

## 决策 4：ASR 代理的确定性口径

- **分歧**：模拟路径下"ASR 转写"从哪来？
- **备选**：(a) 模拟路径从工件元数据"转写"——TTS 模拟器把台词编码进工件，错字率由
  参数种子决定并注入，ASR 代理按种子确定性复现转写，CER 映射得分；(b) 真实 ASR 库
- **结论**：**(a)**——与 004 美学/一致性代理同款"确定性启发式代理（实现哈希即版本）"；
  真实 ASR 服务走 `http_real.py` 骨架（无凭证跳过）
- **依据**：规格 FR-006 + 诚实边界：模拟不等于假装——模拟 ASR 与真实 ASR 受同一
  evaluate 接口契约约束；CER → score 映射口径定点（误差 < 1e-6，规格验收场景 3）。

## 决策 5：同步检测口径（澄清决议落地）

- **结论**：`rule.av_sync` = 音频事件时间戳（模拟器写入工件元数据的语音/音效事件时间）
  与时序元数据（TimingSheet 台词/音效起止）的最大偏差 ≤ `av_sync_threshold_ms`（gate）；
  不做波形-画面对齐（属 F2 剪辑 Agent）
- **依据**：澄清会话 2026-09-20 Q1——声音 Agent 自包含，不依赖视觉工件。

## 决策 6：适配器拆分与成本分账（澄清决议落地）

- **结论**：`agents/sound/platform/base.py` 定义统一协议（生成请求/工件/成本/错误类型 +
  `gen_type`），`simulated.py` 与 `http_real.py` 各含 TTS/SFX/Music 三实现；契约套件
  对三类型 × 双实现同构执行（真实无凭证按用例跳过）；成本按类型分账——
  价目表 `sound.prices.{tts,sfx,music}` 配置，运营表 `gen_type` 列承载分账粒度
- **依据**：澄清会话 2026-09-20 Q2——与真实 API 拓扑一致，接真实渠道是一一映射。

## 决策 7：预算门禁形态

- **结论**：复用 003/004 同构：申请前校验 + 事务内复核扣减（≤ 语义含最小货币单位），
  单轮上限 `sound.exploration_per_round_usd`（可按类型分档配置）；幂等 =
  tree_id/job_id 由 round_id 确定性派生 + 运营表唯一键 `(round_id, params_hash)`
- **依据**：双闭环已验证的纪律，无理由发明第二种（YAGNI）。

## 决策 8：做梦层与周校准的接入成本

- **结论**：**零改动接入**——dreaming 管线对 agent_id 已泛化（005），声音只需 champion
  策略（`policies/history/sound/`）+ 模拟器池 + 无偏性验收（002 套件口径）；
  010 周校准同理（盲评仅对 promo 特判拒绝），sound 走配置纳入
- **依据**：005/010 的泛化设计正是为此；本特性只补声音侧策略与配置，契约测试防回归。

## 决策 9：情绪-配乐匹配分类器

- **结论**：确定性启发式——配乐谐波特征（参数种子决定的音色/速度/调式向量）与输入
  情绪基调标签向量的余弦距离映射得分；低置信（距离超校准带）标注 diagnostics
- **依据**：同决策 4 的"启发式代理 + 实现哈希即版本"哲学；真实模型替换 = 升版本，
  代码路径不变。
