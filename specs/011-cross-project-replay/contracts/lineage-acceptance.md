# 契约：跨项目谱系、一致性验收与做梦接入

> 对应规格 US3 / FR-009~011。实现：`core/replay/cross_lineage.py` + dreaming 侧开关。

## C6 跨项目谱系查询

```
cross_lineage(store, policy_version) -> CrossProjectLineage
```

- policy_version → 跨项目产出的树（project_id 标注）→ 跨项目子策略版本
- JSON 可机读；项目归属完整标注

### 场景

1. 跨项目谱系 → 报表给出跨项目树与子版本（归属标注）
2. 单项目版本 → 正常呈现（跨项目字段为空列表而非缺失）

## C7 一致性验收（合并不改变回放语义）

- 同树在单项目池与合并池回放同策略 → 得分序列一致（合并只扩充候选集）
- 断言可机检（逐树逐策略）

## C8 合并口径无偏性验收（发布阻塞）

- 合并池回放 vs 真实重跑 → Kendall τ ≥ 0.95；注入偏差 100% 拒绝
- 实现：复用 `core/replay/unbiasedness.py` 套件口径 + 合并池夹具

## C9 做梦开关（默认关闭）

- 配置 `replay.pooling.enabled_for_dreaming`（默认 false）
- 关闭/前置条件不足 → 做梦仍用单项目池并注明；开关状态与前置判定入 PoolSnapshot
- 机检：未显式开启时做梦池为单项目池

### 场景

1. 同树双池回放 → 得分序列一致
2. 合并口径 τ ≥ 0.95；注入偏差拒绝
3. 做梦默认 → 单项目池（开关状态入快照）
4. 开关开启但前置条件不足 → 单项目池 + 注明"未启用：前置条件不足"
