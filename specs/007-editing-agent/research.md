## 决策 1：落树节奏——visual 模式（渲染即评即落树）

- **结论**：与 006 相同——剪辑评估信号全部自动可得（五评估器即时算），无外部回流；
  `edit_render_jobs` 运营表只承载渲染中间态，评估完成即节点一次性 INSERT
- **依据**：research/006 决策 1 同一论据。

## 决策 2：模拟渲染器的确定性（含一期 flaky 根因处置）

- **分歧**：mp4 拼接/转场/混音怎么做到逐字节复现？
- **结论**：`agents/editing/render.py`——EDL + 素材帧（夹具/004 模拟帧）→ numpy 程序化
  拼接、转场（叠化 = 定点 alpha 混合）、混音（定点增益叠加）→ mp4；**编码参数固定
  单线程确定性档**
- **依据**：010/006 运维记录显示 004 `test_visual_consistency` 的偶发 flake 根因是
  x264 多线程编码在负载下的非确定性——007 渲染器从设计上消除（编码线程=1 + 定点运算），
  SC-002 逐字节一致才可持续成立。

## 决策 3：EDL 合法性执行前校验（四层）

- **结论**：`agents/editing/edl.py` 四层校验全在执行前：① 引用存在（镜头/音轨在库）；
  ② 入点/出点不越界（0 ≤ in < out ≤ 镜头时长）；③ 场景分区（归属正确 + 场景顺序不降）；
  ④ 转场规则库（类型允许、叠化时长范围、同区跳切检测——配置驱动）
- **依据**：规格 FR-002 + 边界情况——非法 EDL 必须 0 渲染 0 成本；转场规则与门禁
  `rule.transition_rules` 共用同一规则库（配置单一事实源），执行前校验 = 门禁的提前计算。

## 决策 4：节奏基准曲线的配置形态

- **分歧**：基准曲线是什么数据结构？
- **备选**：(a) 特征向量（均值/方差/趋势斜率）目标值 + 容差带；(b) 逐镜头目标序列 + DTW；
  (c) 分段（前/中/后）目标统计 + 段权重
- **结论**：**(c) 分段目标统计 + 段权重**——基准 = `{segments: [{span: [0,0.15), mean_ms, var_ms, weight}, ...]}`，
  成片按相对位置分段统计镜头时长均值/方差，与基准段的加权欧氏距离 →
  `score = 1 − min(1, d / d_cap)`
- **依据**：技术方案原文"方差/趋势与基准曲线的距离"= 统计特征层面；分段 + 段权重
  直接承载附录 A 的短剧形态（"前 3 秒留存权重上调" = 前段 weight 上调），形态切换
  零代码（原则五）；DTW 收益不抵复杂度（YAGNI）。

## 决策 5：judge 摘要函数与版本哈希（澄清 Q1 落地）

- **结论**：`agents/editing/summary.py`——EDL → 确定性结构化文本（逐镜：
  序号/时长/转场/分区标注/音轨标记）；judge 提示词 = 3 固定模板 × 摘要文本成对比较；
  锚点集 = 固定 EDL 集（configs 内嵌）经同一摘要函数产出；**版本号 =
  `1.0.0+j{提示词 BLAKE3 前8}{锚点集前8}{摘要函数前8}`**
- **依据**：澄清决议——叙事信息在 EDL 结构里；摘要函数是 judge 输入的形成环节，
  其变更同提示词变更一样改变打分行为，必须入版本（原则一）。

## 决策 6：judge 平局与 LLM 计费

- **依据**：规格边界情况 + 原则三。

## 决策 7：预算门禁/幂等/两段式——同构复用
