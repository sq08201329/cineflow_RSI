## 用户场景与测试 *（必填）*

### 用户故事 1 - 剪辑决策执行与确定性渲染合成（优先级：P1）🎯 MVP

剪辑生产线运行一轮探索：当前策略对输入（候选镜头库 = 视觉工件引用集 + 每镜元数据、
场景分区约束——场景顺序固定、每场景指定镜头子集、区内自由、可选音轨引用 + 时序元数据）
产出剪辑决策 **EDL**（镜头序列、每镜入点/出点、
转场类型与时长、音轨摆放）→ 执行器经预算门禁（单轮 ≤ 配置上限，事务扣减、轮次幂等）
调用渲染合成适配器 → 产出成片工件（mp4，BLAKE3 内容寻址）与成本入账。适配器双实现：
确定性模拟渲染器（EDL + 镜头素材帧 → 程序化拼接/转场/混音 → mp4，逐字节可复现）为
开发/CI 默认；真实渲染服务适配器骨架（无凭证跳过）。中间态落可变运营表，渲染与评估
齐备后节点一次性 INSERT（visual 模式，无外部回流）。

**为什么是这个优先级**: EDL 决策与渲染合成是剪辑闭环的本体——没有成片落树，节奏评估、
judge、进化无从谈起；渲染的中等成本纪律（原则三）也在此落地。

**独立测试**: 用确定性模拟渲染器 + 夹具镜头库跑一轮：EDL→mp4 逐字节复现、预算门禁、
幂等重建、成本入账、两段式落盘逐断言；不接评估器与做梦层即可交付"成片可落树"的价值。

**验收场景**:

1. **Given** 夹具镜头库（≥6 镜头）与场景分区约束, **When** 执行一轮剪辑探索, **Then** 策略产出合法 EDL，渲染出 mp4 成片内容寻址落库，成本入账，节点一次性 INSERT
2. **Given** 同一 EDL 与镜头库, **When** 模拟渲染器执行两次, **Then** 两个 mp4 逐字节一致（哈希相等）
3. **Given** 单轮渲染预算上限, **When** 策略请求超上限的渲染次数, **Then** 门禁拒绝超额部分，已执行部分成本照常入账
4. **Given** 同轮次重复触发, **When** 幂等检查, **Then** 0 重复渲染、0 重复扣费、节点不重复
5. **Given** EDL 引用镜头库中不存在的镜头或越界入点/出点, **When** 执行前校验, **Then** 拒绝且 0 渲染调用、0 成本

### 用户故事 2 - 评估器组合与合成评分（优先级：P2）

评估工程师为剪辑节点打分：硬规则三门禁——`rule.duration_compliance`（成片总时长 ∈
目标时长 ± 容差，配置）、`rule.shot_distribution`（镜头时长分布统计：最短/最长镜头
限制，防碎片化与拖沓）、`rule.transition_rules`（转场合法性规则库：非法转场、叠化
时长范围、跳切检测）；代理模型——`proxy.pacing_curve`（镜头时长序列的方差/趋势与
**类型片基准曲线**的距离，基准曲线形态配置化——短剧形态前 3 秒留存权重上调即换曲线）；
judge——`judge.narrative_flow`（成对比较片段叙事流畅度：**judge 输入 = EDL 结构化文本
摘要**（镜头序列/时长/转场的文字描述——叙事信息在剪辑决策结构里，不在模拟渲染的占位
画质里），3 个固定提示词 × 冻结锚点集（锚点 = 固定 EDL 集经确定性摘要产出）投票，
提示词/锚点哈希入版本号，走 LLM 网关计费，Mock 后端确定性响应使比较可复现）。合成 = 门禁 + 加权求和（权重形态
配置）+ 定点归一（6 位小数）。

**为什么是这个优先级**: 剪辑的评估信号比视觉更弱（叙事流畅度高度主观），judge 层是
必要的也是风险最高的（reward hacking 面）——版本冻结与锚点集纪律必须一次做对；
依赖 US1 的成片落树。

**独立测试**: 构造已知剪辑属性的成片夹具（时长合规/违规、碎片化镜头序列、非法转场、
节奏贴近/背离基准曲线）：五评估器得分、门禁语义、judge 委员会投票与版本哈希、定点
归一逐断言。

**验收场景**:

1. **Given** 总时长超出目标 ± 容差的成片, **When** 评估, **Then** duration 门禁判 0，总分直接为 0
2. **Given** 含低于最短镜头限制的碎片化序列, **When** 评估, **Then** shot_distribution 门禁判 0
3. **Given** 非法转场（规则库禁止的组合）, **When** 评估, **Then** transition 门禁判 0；合法转场通过
4. **Given** 镜头时长序列贴近/背离基准曲线两组成片, **When** proxy.pacing_curve 评估, **Then** 前者得分显著高于后者，距离口径误差 < 1e-6
5. **Given** judge 委员会, **When** 成对比较, **Then** 3 提示词 × 冻结锚点集投票产胜率，提示词/锚点哈希入版本号，LLM 调用全过网关计费；同比较重跑结果逐位一致

### 用户故事 3 - 回放接入、无偏性验收与做梦进化（优先级：P3）

做梦工程师把剪辑 Agent 接入自动进化：剪辑树冻结入池（train/validation 分树沿用既有
口径）→ 做梦层生成剪辑策略候选（剪辑节奏与结构策略代码）→ 沙箱全池回放（回放零渲染
——EDL 重放只读历史节点，审计断言）→ reward 口径复用 → 人工审批。**一致性验收
（发布阻塞）**：回放打分 vs 真实重跑 Kendall τ ≥ 0.95；注入偏差 100% 拒绝；产出首轮
进化曲线基线。剪辑纳入 010 周校准盲评范围（judge 层需人评锚点监控漂移——F7 数据源）。

**为什么是这个优先级**: 自动进化是立项书 F2 的闭环含义与里程碑验收线；剪辑是首个
"judge 权重实质影响进化方向"的 Agent，无偏性与锚点监控是它的安全网。

**独立测试**: 剪辑夹具池跑无偏性对照（τ ≥ 0.95 + 注入拒绝）；一轮做梦（演示档）产出
reward 排名与首轮基线；010 盲评对 editing 正常产出。

**验收场景**:

1. **Given** 剪辑模拟器池 ≥2 棵树, **When** 无偏性验收, **Then** 回放与真实重跑得分序列 Kendall τ ≥ 0.95
2. **Given** 注入偏差的评估器或篡改 judge 胜率, **When** 无偏性验收, **Then** 100% 被拒绝
3. **Given** 一轮做梦（剪辑策略候选）, **When** 沙箱全池回放, **Then** 渲染调用计数恒为 0（审计断言），reward 口径与既有 Agent 一致
4. **Given** 首轮进化完成, **When** 查看产出, **Then** 首轮基线落盘（进化曲线起点）
5. **Given** 010 周校准, **When** 对 agent_id="editing" 生成盲评清单, **Then** 正常产出（仅 promo 特判拒绝）

### 边界情况

- 镜头库为空或不足最小镜头数：执行前校验拒绝（0 渲染 0 成本），注明"素材不足"
- 素材总长 < 目标时长下限：duration 门禁必然违规——策略应被拒绝于执行前（可行性预检），如实落 FAILED 节点并注明
- EDL 转场与相邻镜头组合非法：执行前规则库校验拒绝（不等渲染后门禁才发现）
- EDL 跨场景分区选镜或破坏场景顺序：执行前校验拒绝（场景分区违规，0 渲染 0 成本）
- judge 委员会平局（3 提示词投票 1.5/1.5 类）：胜率 0.5 如实记录，不做二次裁决
- 音轨引用缺失：按无音轨渲染（节奏评估仅镜头时长序列），注明"无音轨"
- 渲染部分失败：失败条目成本照常入账，该备选记 FAILED，轮次继续
- 基准曲线配置缺失（形态未配置剪辑基准）：合成评分拒绝启动并报错（不允许静默无基准打分）

## 需求 *（必填）*

### 功能需求

- **FR-001**: 系统必须提供剪辑探索执行器：输入 = 候选镜头库（工件引用 + 元数据）+ 场景分区约束（场景顺序固定，每场景指定镜头子集，区内排序/裁剪/转场自由）+ 可选音轨（引用 + 时序元数据）+ 当前策略；输出 = 成片工件（mp4 内容寻址）+ 成本入账 + 发现树节点
- **FR-002**: 剪辑决策必须表示为 EDL：镜头序列、每镜入点/出点、转场类型与时长、音轨摆放（按时间戳，承接 006 边界决议）；EDL 合法性必须执行前校验：引用存在、入点/出点不越界、场景分区归属与顺序合规、转场规则库合法——违规即拒绝（0 渲染 0 成本）；EDL 规范化 JSON 相等 = 回放精确匹配键
- **FR-003**: 渲染适配器必须双实现：确定性模拟渲染器（EDL + 素材帧 → 程序化拼接/转场/混音 → mp4 逐字节复现）+ 真实渲染服务骨架；同一套契约套件（无凭证跳过）
- **FR-004**: 预算门禁必须执行：单轮渲染 ≤ 配置上限，事务扣减防双花，轮次幂等（round_id 派生 + 唯一键）；超界拒绝，FAILED 成本照常入账
- **FR-005**: 两段式落盘必须执行：渲染中间态落可变运营表，渲染与评估齐备后节点一次性 INSERT
- **FR-006**: 硬规则评估器必须实现三门禁：`rule.duration_compliance`（总时长 ± 容差）、`rule.shot_distribution`（最短/最长镜头限制）、`rule.transition_rules`（转场规则库合法性）；gate 违规总分直接为 0；阈值与规则库全配置化
- **FR-007**: 代理评估器必须实现 `proxy.pacing_curve`：镜头时长序列统计（方差/趋势）与类型片基准曲线的距离映射得分；基准曲线形态配置化（configs/*.yaml），缺基准拒绝启动
- **FR-008**: judge 评估器必须实现 `judge.narrative_flow`：输入 = EDL 结构化文本摘要（确定性摘要函数产出，镜头序列/时长/转场描述），3 固定提示词 × 冻结锚点集（固定 EDL 集经同一摘要函数产出）成对比较投票；提示词/锚点/摘要函数哈希入版本号（004 同款纪律）；LLM 调用全过网关计费；同比较重跑逐位一致（Mock 后端确定性响应）
- **FR-009**: 合成评分必须 = 三门禁 + 加权求和（权重形态配置）+ 定点归一（6 位小数）；全部评估器版本冻结、deterministic=True（judge 经锚点集冻结与缓存满足确定性语义，同 004）
- **FR-010**: 剪辑树必须接入回放模拟器池（observed/probe/规范化精确匹配/UNKNOWN 复用 002），回放零渲染零生成（审计断言）；train/validation 分树（最近树永远只做 validation）
- **FR-011**: 无偏性验收必须执行：回放 vs 真实重跑 Kendall τ ≥ 0.95 发布阻塞；注入偏差 100% 拒绝
- **FR-012**: 做梦层必须支持剪辑策略进化（候选静态检查 → 沙箱回放 → reward 复用口径 → 人工 approve）；剪辑必须纳入 010 周校准盲评范围（judge 层人评锚点）

### 关键实体 *（如果功能涉及数据）*

- **剪辑决策表（EditDecisionList / EDL）**: 一次剪辑的完整决策——镜头序列（引用 + 入点/出点）、转场（类型/时长）、音轨摆放；规范化 JSON 即回放匹配键
- **镜头库条目（ShotEntry）**: 候选镜头——工件引用、时长、来源节点、所属场景分区、元数据（视觉评估得分可供策略参考但不入剪辑打分）
- **场景分区（SceneStructure）**: 粗剪结构约束——场景有序列表，每场景指定镜头子集；EDL 合法性校验的依据（执行前拒绝分区违规）
- **渲染作业（EditRenderJob）**: 渲染任务的运营中间态——EDL 哈希、状态、预估/实际成本、成片引用；两段式落盘的可变侧
- **基准曲线（PacingBaseline）**: 类型片节奏基准——镜头时长分布/趋势曲线的配置形态（电影/短剧分档）
- **剪辑策略（EditingPolicy）**: 被进化对象——镜头选择/排序/裁剪/转场决策代码（OptimalPolicy.solve() 形态）
- **成片工件（FilmArtifact）**: mp4 内容寻址引用——哈希、总时长、镜头数、音轨标记

## 假设

- 真实渲染服务不接凭证：适配器骨架 + 确定性模拟双实现，真实接入是凭证配置动作（诚实边界同 003/004/006）
- 候选镜头库以夹具/006 工件提供；与视觉 Agent 的真实镜头供给契约在试水作品集成时对齐（里程碑周 11~12），本特性只定义剪辑侧输入 schema
- 音轨为可选输入（006 工件引用 + TimingSheet）；EDL 音轨按时间戳摆放即对齐，波形级同步检测已由 006 av_sync 承担，剪辑不重做
- 模拟渲染器的"程序化拼接/转场/混音"只需剪辑属性可控（总时长/镜头时长序列/转场类型可从 EDL 确定性复现），不追求真实画质
- judge 委员会沿用 004 模式（3 提示词 × 冻结锚点集 + Mock 后端确定性）；真实 judge 模型接入是网关配置动作
- judge 漂移自动检测（F7）不在本特性；本特性只保证剪辑入 010 盲评范围、锚点数据按 010 口径积累
- 剧本/分镜 Agent 未接入前，场景分区约束以夹具提供（场景有序 + 镜头子集归属的最小表达）
