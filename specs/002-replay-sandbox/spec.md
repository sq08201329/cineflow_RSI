# 功能规格说明：回放模拟器与沙箱化策略执行

**功能分支**: `002-replay-sandbox`

**创建日期**: 2026-09-18

**状态**: 草稿

**输入**: 用户描述："实现一期里程碑周 4~6 交付物：core/replay 回放模拟器引擎（前缀可观测拦截、UNKNOWN 语义、虚拟时钟与并行惩罚）+ core/sandbox 沙箱化策略执行 + 对抗测试套件（作弊策略全拦截）+ 无偏性验收（回放 vs 真实轨迹 Kendall τ ≥ 0.95）。验收：作弊策略全拦截；无偏性 τ≥0.95。"

**约束来源**: 项目宪章 `.specify/memory/constitution.md`（原则三、四为不可协商项）；工程细节参照 `docs/CineFlow开发文档.md` §3、§4。依赖功能 001 已交付的发现树存储与评估器框架。

## 用户场景与测试 *（必填）*

### 用户故事 1 - 零成本回放探索策略（优先级：P1）

策略开发工程师把一棵（或同 Agent 多棵合并的）已冻结发现树转成模拟器，让候选探索策略
在其中运行：策略只能看到"按其走法本应已揭示"的节点信息；选择父节点扩展（probe）时，
系统返回与该父节点、该生成参数**精确匹配的真实历史节点**的得分与成本；无匹配走法返回
`UNKNOWN` 且策略不得获得得分；全程零生成调用；虚拟时钟记录决策轮与有效串行轮，
支撑并行惩罚计算。回放产出完整轨迹（得分曲线、probe 数、成本），供做梦层计算奖励。

**为什么是这个优先级**: 回放是"做梦"机制的核心引擎——零成本试错、策略进化、成本模型
全部建立在它之上（宪章原则三）。没有正确的回放语义，沙箱与对抗测试都无的放矢。

**独立测试**: 用手工构造的小型发现树回放一个确定性手工策略，逐断言轨迹与手工预期
一致（揭示顺序、UNKNOWN 语义、时钟计数、预算拒绝），无需沙箱与真实 Agent 即可交付
"历史可回放"的价值。

**验收场景**:

1. **Given** 一棵含已知节点的冻结历史树, **When** 策略 probe 的父节点与生成参数与历史节点精确匹配, **Then** 返回这些真实节点的得分/成本/观测，节点转为已揭示
2. **Given** 某走法历史上从未发生, **When** 策略 probe, **Then** 返回 `UNKNOWN`，策略不获得任何得分与节点信息
3. **Given** 完整回放过程, **When** 审计生成类调用计数, **Then** 恒为 0（回放不做任何新生成）
4. **Given** 一批 k 个节点的揭示、并行工作者数 W, **When** 计入时钟, **Then** 有效串行轮增加 ⌈k/W⌉
5. **Given** 策略 probe 次数达到预算上限, **When** 再次 probe, **Then** 拒绝并提示预算耗尽
6. **Given** 多棵同 Agent 历史树合并的模拟器池, **When** 策略 probe, **Then** 候选节点取自池内全部树的真实历史节点

### 用户故事 2 - 沙箱化执行与前缀拦截（优先级：P2）

平台工程师把（做梦层产出的）不可信策略代码放入隔离执行环境运行：策略只能通过 IPC
调用 `observed()` 与 `probe()` 两个入口；模拟器的未揭示节点在策略侧**物理不可达**
（不同进程、不传对象）；沙箱无网络、不持有对象存储凭证、素材库只读挂载、资源限额。
对抗测试套件常驻 CI：三类典型作弊策略（反射偷看未揭示节点、计时侧信道推断隐藏得分、
用内容哈希反查对象存储）必须全部被拦截，任一失守即阻塞合并。

**为什么是这个优先级**: 前缀泄露是"低概率、高影响"缺陷，一旦发生全部实验结论失真
（宪章原则四）。它依赖 P1 的回放语义才有效用，但隔离与拦截机制本身可独立验证。

**独立测试**: 运行对抗测试套件——三个作弊策略在沙箱中逐一尝试偷取未来信息，全部
以预期方式失败/被拒；无需完整回放正确性即可证明"拦截成立"。

**验收场景**:

1. **Given** 作弊策略尝试遍历模拟器对象属性读取未揭示节点（peek_latent）, **When** 在沙箱中执行, **Then** 失败——策略进程内不存在模拟器对象
2. **Given** 作弊策略用响应时间推断隐藏得分（timing_side_channel）, **When** 测量 probe 响应时间, **Then** 响应时间含固定抖动，与隐藏得分无相关性可被统计检验拒绝
3. **Given** 作弊策略用 artifact_hash 反查对象存储（hash_oracle）, **When** 尝试访问, **Then** 沙箱内无对象存储凭证/网络，访问被拒
4. **Given** 策略代码尝试网络访问、文件写入、import 白名单外模块, **When** 静态检查与运行时隔离生效, **Then** 被拒绝/失败
5. **Given** 对抗测试套件, **When** CI 运行, **Then** 全部作弊策略被拦截，任一失守即合并阻塞

### 用户故事 3 - 回放无偏性验收（优先级：P3）

评估工程师在新评估器或新 Agent 上线前运行无偏性验收：用策略 π 在线跑一次记录真实
轨迹 T_real，再在由**其他树**组成的模拟器池中回放同版本 π；两条轨迹的得分序列
Kendall τ ≥ 0.95 才允许上线，否则拒绝并输出对比报告。故意注入偏差的回归用例必须
100% 被判拒绝。

**为什么是这个优先级**: 它是回放正确性的上线门禁（宪章质量门禁清单中的发布阻塞项）。
依赖 P1 的回放引擎与 P2 的可信执行，是三者中最上层的验收工具。

**独立测试**: 构造已知一致的轨迹对（应通过）与已知偏移的轨迹对（应拒绝），验证
τ 计算与门槛判定；再对故意注入偏差的模拟器变体验证 100% 拒绝。

**验收场景**:

1. **Given** 真实轨迹与在无泄漏模拟器中的回放轨迹, **When** 计算得分序列 Kendall τ, **Then** τ ≥ 0.95 判定通过
2. **Given** 故意注入偏差的回放轨迹, **When** 验收, **Then** 100% 判定拒绝并输出差异明细
3. **Given** 验收执行完成, **When** 查看报告, **Then** 输出 τ 值、轨迹对比与判定结论（JSON）

---

### 边界情况

- probe 的生成参数与历史节点部分匹配（如缺字段）：按精确匹配语义返回 `UNKNOWN`，不做模糊匹配
- 历史中该走法下的 FAILED 节点：照常揭示（得分为空、成本有效），策略可据此决策
- 同一父节点与参数下历史有多个节点：全部揭示，虚拟成本按批计入
- 策略代码运行超时/崩溃：本次回放判失败并记录诊断，不污染模拟器状态
- 策略试图把对象引用带出沙箱（序列化逃逸）：IPC 边界只允许值语义数据，引用不可达
- 树未冻结（仍在写入中）被加入模拟器池：拒绝——只允许已冻结树入池
- 模拟器池为空：回放直接返回空轨迹而非崩溃
- 预算为 0 的策略：不得 probe，仅可观察已揭示空集并返回结论

## 需求 *（必填）*

### 功能需求

- **FR-001**: 系统必须由一棵或多棵**已冻结**的同 Agent 发现树构建回放模拟器；未冻结的树入池必须被拒绝
- **FR-002**: 回放状态 = 已揭示节点集合；策略的唯一信息入口为 `observed()`（只暴露已揭示节点、且只暴露观测上下文允许的字段）与 `probe()`
- **FR-003**: `probe(父节点, 生成参数)` 必须返回与该父节点、该参数**精确匹配的真实历史节点**，揭示之并计入虚拟成本；**禁止**模糊匹配或插值编造
- **FR-004**: 无匹配走法必须返回 `UNKNOWN`，策略不得获得得分与任何节点信息
- **FR-005**: 回放全程生成类预算恒为 0，**禁止**任何新生成；违反即回放失败
- **FR-006**: 虚拟时钟必须记录决策轮数与有效串行轮数；一批 k 个揭示消耗 ⌈k/W⌉ 个有效串行轮（W 来自形态配置）
- **FR-007**: 策略接口必须为 `solve(env, budget) -> node_id`；budget 限制 probe 总数，超限拒绝；线上专属生成预算在回放中恒 0
- **FR-008**: 策略必须在隔离执行环境中运行，仅经 IPC 访问两个入口；模拟器未揭示状态对策略进程**物理不可达**（不同进程、不传递对象引用）
- **FR-009**: 沙箱必须满足：无网络访问、无对象存储凭证、素材库只读挂载、CPU/内存/时限资源限额
- **FR-010**: 对抗测试套件必须覆盖三类作弊策略：反射偷看未揭示节点、计时侧信道、哈希反查对象存储；全部拦截为 CI 合并阻塞门禁
- **FR-011**: probe/observed 响应时间必须加入固定抖动，不得携带与隐藏得分相关的时序信息
- **FR-012**: 无偏性验收必须计算真实轨迹与回放轨迹得分序列的 Kendall τ，门槛 ≥ 0.95，低于即拒绝上线，并输出 JSON 对比报告
- **FR-013**: 回放必须输出完整轨迹（逐轮最优得分曲线、probe 计数、有效串行轮、成本合计），供做梦层奖励函数（pareto_auc − λ·并行惩罚）直接消费
- **FR-014**: FAILED 历史节点必须可回放：照常揭示，得分为空、成本有效
- **FR-015**: 策略代码版本必须以其代码内容的 BLAKE3 前 12 位为版本号，回放记录必须携带策略版本以维持谱系可查

### 关键实体 *（如果功能涉及数据）*

- **回放模拟器（ReplaySimulator）**: 由冻结历史树构建的只读回放环境——维护已揭示/未揭示节点集合，提供 `observed()`/`probe()`，产出轨迹
- **观测（Observation）**: 已揭示节点对策略可见的投影——只含观测上下文允许的字段
- **探针结果（ProbeResult）**: 一次揭示的产出——匹配节点列表或 `UNKNOWN`，及虚拟成本
- **虚拟时钟（VirtualClock）**: 决策轮数、有效串行轮数、并行工作者数 W；支撑并行惩罚
- **探索策略（ExplorationPolicy）**: 被进化/被评估的对象，`solve(env, budget)` 形态，版本号 = 代码 BLAKE3 前 12 位
- **回放轨迹（ReplayTrajectory）**: 一轮回放的完整记录——逐轮最优得分曲线、probe 数、串行轮数、成本、策略版本
- **沙箱（Sandbox）**: 策略的隔离执行环境——IPC 边界、资源限额、无网络/无凭证
- **无偏性报告（UnbiasednessReport）**: τ 值、轨迹对比、判定结论

## 成功标准 *（必填）*

### 可衡量结果

- **SC-001**: 三类作弊策略 100% 被拦截（对抗测试 CI 全绿，任一失守即合并阻塞）
- **SC-002**: 无偏性验收对一致轨迹 100% 放行、对故意注入偏差的轨迹 100% 拒绝
- **SC-003**: 任意回放过程中生成类调用计数恒为 0（自动化审计断言）
- **SC-004**: 任何 `UNKNOWN` 走法下策略获得的得分泄漏为 0
- **SC-005**: 单元测试覆盖率 ≥ 85%（延续宪章门禁）
- **SC-006**: 由 3 万节点历史树构建模拟器、回放一套参考策略的完整流程在开发环境 < 10 分钟完成
- **SC-007**: 计时侧信道回归检验：全部 probe/observed 响应时间落在时延量子整数倍上，且响应时间与隐藏得分的相关性不显著（|Pearson r| < 0.1）——抖动生效且可判定

## 假设

- 策略语言为 Python，与宿主同版本；容器运行时（gVisor 等）的具体选型与 IPC 机制在 plan 阶段决定
- 本特性一并交付 `policies/` 的策略基类与版本管理（回放需要可执行策略形态）；策略历史版本目录 `policies/history/` 随之建立
- 做梦层（LLM 生成候选策略代码）**不在**本特性范围——本特性交付"给定策略代码可沙箱回放、可打分、作弊必拦截"的能力
- 模拟器池仅支持同 Agent 多树合并；跨项目合并回放为二期事项（宪章治理规则已列明）
- human 评估器数据（人评、平台回流）在落盘时已冻结为常数，回放直接读取即可，本特性无需特殊处理
- 无偏性验收的在线轨迹采集（真实跑一次策略）在本特性中以录制的轨迹夹具模拟，真实采集属 Agent 闭环里程碑
