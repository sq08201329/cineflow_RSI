# 阶段 0 调研：剧本 Agent 降级模式（009-script-agent-degraded）

> 每个决策 = 分歧点 → 备选 → 结论 → 依据。规格：[spec.md](spec.md)（含 2026-09-20 澄清两条）。

## 决策 1：包名与 agent_id = `screenplay`

- **分歧**：`agents/script/` 还是 `agents/screenplay/`？
- **结论**：**`agents/screenplay/`，agent_id = "screenplay"**
- **依据**：仓库内 `scripts` 已有语义（ops/`.specify/scripts` 与脚本文件），`script`
  一词在本项目里指脚本程序；剧本的准确词是 screenplay，避免日志/查询里"script 节点"
  与"脚本"歧义。spec 目录名保留立项书编号 `009-script-agent-degraded`，代码侧用 screenplay。

## 决策 2：三段产出分阶段落树，judge 只作用于大纲阶段

- **分歧**：大纲→分场→剧本是三轮独立产出还是一个节点的三个阶段？
- **结论**：**分阶段独立落树**（job/节点的 `stage: outline | scenes | script` 字段），
  每阶段独立评估与计费；**`judge.dramatic_tension` 只评大纲阶段**（技术方案原文"哪个
  **大纲**的戏剧张力更强"），非大纲阶段的 judge 分量标记"不适用"，合成按适用分量归一
- **依据**：技术方案 §2.2 剧本行的 judge 限定于大纲；合成归一语义已有既有实现
  （004/006/007/008 同一口径），不新造。

## 决策 3：硬规则解析口径（确定性优先）

- **结论**：剧本工件携带**结构化标记**（节拍清单 + 场景头 + 角色表，确定性可解析）——
  ① `beat_structure` 校验三幕/序列结构与关键节拍存在性（配置节拍表）；② `page_minutes`
  按 `lines_per_page`（配置）换算页数 ∈ 目标时长 ± 容差；③ `scene_character` 校验场景
  出场角色 ∈ 角色表、地点一致；④ `dialogue_action_ratio` 统计对白/动作行比例落配置区间
- **依据**：评估器必须确定性（原则一）——"读懂自由文本"不可复现，结构化标记是前提；
  工件 schema 与 008 分镜输入（ScriptSegment）同源，避免两套剧本表示。

## 决策 4：代理模型两个（实体一致性 / 时间线冲突）

- **结论**：`proxy.entity_consistency` = 角色名规范化匹配 + 别名表（配置）——
  同名异写/指代歧义产诊断；`proxy.timeline_conflict` = 场景标注时间与剧本内部既定顺序
  的单调性冲突检测；两者确定性、实现哈希入版本号
- **依据**：技术方案 §2.2 剧本代理行；确定性启发式是全线惯例（004/006/008 同款）。

## 决策 5：生成的"非确定性收敛"——网关缓存是回放可复现的前提

- **结论**：LLM 生成经网关（缓存键 = 输入摘要 + 模型 + 参数），命中缓存即逐字节复现；
  节点落盘携带缓存键与响应哈希；**回放路径零 LLM 调用**（只读历史节点，审计断言）
- **依据**：原则三——回放不得触发生成；原则一——评估器确定性由"读落盘工件"保证，
  生成的非确定性被缓存收敛在线上探索阶段。

## 决策 6：人工提交通道复用既有机制

- **结论**：策略提交 = `policies/history/screenplay/{version}.py` + meta.json
  （005 布局）→ 复用 002 静态检查 → 回放对比用 `dreaming/reward.py` 的 pareto_auc
  曲线口径与 003 的对比报告形态 → 采纳/拒绝留痕（003 approve 的形态推广到人工决策）
- **依据**：全线一致，不新造版本/检查/对比机制；参数调整走 configs（澄清 Q2）。

## 决策 7：禁止自动进化的工程落点

- **分歧**：原则六的"禁止"写在哪？
- **备选**：(a) 代码硬编码黑名单；(b) 配置 `dreaming.no_auto_evolve_agents` + 显式拒绝异常
- **结论**：**(b) 配置驱动 + 显式拒绝异常（`AutoEvolutionForbiddenError`）**，默认值含
  `[screenplay, dev]`；dreaming 管线在候选生成前检查，命中即拒绝（非静默跳过）；
  契约测试断言拒绝语义 + 审计断言
- **依据**：原则五配置化（形态可换）+ 原则六可审计；硬编码黑名单虽更"安全"但违反
  配置化惯例，且配置有测试兜底（默认值断言 + 拒绝行为断言）。

## 决策 8：升级判据材料的自动判定（澄清 Q1 落地）

- **结论**：`upgrade_evidence.py` 产出 `calibration/upgrade-events/{period}.json`（新目录
  或 `screenplay/` 数据目录下）——含判据阈值快照、原始数值、系统结论（达标/不达标）、
  推翻记录；阈值全部来自 configs（相关系数 target 复用 010 的 reliability_target 语义）；
  阈值缺失即报错（不允许静默"无判据"）
- **依据**：澄清决议——判定必须可机检；"不达标"是系统的自动写入，人推翻只增记录。

## 决策 9：与 008 分镜的 schema 对接

- **结论**：剧本工件 → `ScriptSegment`（场景/台词/行动/关键行/情绪）的**导出函数**由
  本特性提供（`export_segment()`），008 的夹具可切换为真实导出；schema 快照断言双向锁定
- **依据**：008 假设明确"剧本 Agent 真实产出契约在其接入时对齐"；本特性即该接入点。
