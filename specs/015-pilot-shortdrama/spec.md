### 用户故事 1 - 短剧形态配置与零代码切换（优先级：P1）🎯 MVP

产线负责人切换形态：新增 `configs/shortdrama.yaml`（形态标识、评估器权重与阈值、节奏基准
曲线换短剧体量、外环频率改日级、预算与并行度下调、时长/规格参数）→ 同一条链在
`movie` 与 `shortdrama` 两套配置下运行 → **差异全部来自配置**（零代码分支）：评估器
权重/阈值生效、节奏基准曲线替换、预算上限生效、产物规格（时长/分辨率）按配置产出。
**代码侧零改动**必须可证：切换只改 `--config` 参数（机检：无形态分支代码）。

**为什么是这个优先级**: 这是"同一套基建、多形态复用"这一核心资产观的技术载体——
配置化承诺若不成立，试水作品就只是又一次定制开发，公司的复利资产无从谈起。

**独立测试**: 同一输入 + 两套配置各跑一轮：评估器权重差异、基准曲线差异、预算门禁
差异、产物规格差异逐断言；并断言代码路径无形态分支（静态扫描）。

**验收场景**:

1. **Given** `configs/shortdrama.yaml` 与既有 `movie.yaml`, **When** 同一条链分别运行, **Then** 两轮均成功，差异均可归因到配置项（权重/阈值/曲线/预算/规格）
2. **Given** 短剧配置, **When** 运行, **Then** 剪辑节奏基准曲线为短剧体量（前段权重上调，附录 A 口径）且代理得分按新曲线计算
3. **Given** 短剧配置的预算上限（低于电影形态）, **When** 策略请求超限, **Then** 门禁按新上限拒绝（配置生效而非代码硬编码）
4. **Given** 代码库, **When** 静态扫描形态分支（如 `if form == "shortdrama"` 类分支）, **Then** 零命中（形态差异只存在于配置）
5. **Given** 两套配置的运行产物, **When** 比较规格, **Then** 时长/分辨率等按各自配置产出（短剧体量）

### 用户故事 2 - 六环节链式交接（优先级：P2）

产线把六个环节串成真实产线：**剧本(009) → 分镜(008) → 视觉(004) → 声音(006) →
剪辑(007) → 宣发(003)**，每段有明确的**产物 schema 对接**与验收（当前状态：各 Agent
输入全来自夹具，`export_segment` 已备但未被生产路径调用）：
① 剧本工件 → `ScriptSegment`（009 的 `export_segment`，已有）→ 分镜输入
② 分镜 `ShotList` → 视觉生成参数（每镜的生成参数建议：景别/时长/风格）
③ 视觉工件（片段）+ 声音工件（音轨 + 时序）→ 剪辑的**镜头库与音轨**
④ 剪辑成片 → 宣发的物料素材来源
每段交接的 schema 必须**双向锁定**（上游导出与下游输入逐字段一致，快照断言防漂移）；
上游缺失/不合格（如分镜未过门禁）→ 下游环节**如实拒绝启动**并注明（不静默降级）。

**为什么是这个优先级**: 交接是"能不能成为一条产线"的分水岭——没有它，六个 Agent 只是
六个独立工具；而交接契约的漂移正是最隐蔽的集成风险（各自单测全绿、串起来失败）。

**独立测试**: 六段交接逐段契约测试（上游产物 → 下游输入，schema 与语义双向断言）；
上游不合格时的拒绝路径断言。

**验收场景**:

1. **Given** 剧本阶段的产物, **When** 导出为 `ScriptSegment`, **Then** 分镜侧校验通过（双向 schema 快照一致）
2. **Given** 分镜 `ShotList`, **When** 生成视觉生成参数, **Then** 每镜参数齐备（景别/时长/风格）且视觉侧接受
3. **Given** 视觉片段工件与声音工件, **When** 组装剪辑输入, **Then** 镜头库（引用 + 时长 + 元数据）与音轨（引用 + 时序）齐备且剪辑侧校验通过
4. **Given** 剪辑成片工件, **When** 传给宣发, **Then** 物料素材引用与元数据齐备且宣发侧校验通过
5. **Given** 上游环节未过门禁（如分镜被判 0）, **When** 下游启动, **Then** 如实拒绝并注明上游原因（不静默降级、不伪造输入）

### 用户故事 3 - 端到端编排与可复现样片（优先级：P3）

产线负责人发起一次试水运行：**自研轻量 DAG 执行器**按六环节依赖编排（宪章禁止 Airflow
类静态框架）→ 逐环节执行（各环节仍走自己的门禁：预算/幂等/落树）→ 产出**可复现样片**
（全模拟生成器链路，同输入同配置逐字节可复现）+ **全程成本账目**（按环节与形态汇总，
与各 Agent 落盘成本对账一致）+ **产物清单**（工件哈希与环节归属）+ **各环节评估分量与
进化状态快照**（评分构成、坍缩状态、漂移状态摘要）。运行中断（某环节失败）→ 已完成的
环节产物保留（不重跑），失败点与原因如实记录，可修复后从断点续跑。

**为什么是这个优先级**: 这是"试水"的实体——它把六段交接串成一次可复现的完整产出，
并给出公司级决策所需的全链路证据（成本、质量分量、健康状态）；依赖前两个故事。

**独立测试**: 一次完整运行：DAG 依赖顺序正确、样片逐字节可复现、成本对账一致、清单
字段齐全、断点续跑不重跑已完成环节；同输入两次运行产物一致。

**验收场景**:

1. **Given** 短剧配置与输入素材, **When** 发起一次试水运行, **Then** 六环节按依赖顺序执行，产出**自包含样片包**（成片 + 各环节产物引用 + 清单 + 成本账目 + 状态快照）
2. **Given** 同输入同配置, **When** 运行两次, **Then** 样片与产物清单逐字节一致（可复现）
3. **Given** 运行中的成本, **When** 对账, **Then** 编排汇总的成本与各 Agent 落盘成本一致（零差异）
4. **Given** 某环节全部候选被判 0, **When** 运行推进, **Then** 环节内换候选重试；**全部不合格才终止**整条运行，失败点与全部候选的判 0 理由如实记录（不合格产物绝不传给下游）
5. **Given** 运行在某环节失败后修复重跑, **When** 续跑, **Then** 已完成环节产物保留（不重跑），从失败点继续
6. **Given** 编排器实现, **When** 检查依赖, **Then** 使用自研轻量 DAG 执行器（无 Airflow 类外部框架依赖）；执行器位于 `core/orchestration/` 且不含任何形态/环节业务概念（静态断言），链定义在业务侧
7. **Given** 运行完成, **When** 查看状态快照, **Then** 含各环节评分构成、坍缩状态与漂移状态摘要（如实呈现，缺失则空态）

### 边界情况

- 输入素材不足（剧本场景数或镜头数低于配置下限）：编排在**启动前**预检拒绝（不产生成本），注明缺口
- 某环节门禁判 0（如分镜语法违规）：该候选记为不合格、环节内换候选重试；同一环节**全部候选不合格**才终止运行（如实记录，不自动放宽、不传下游）
- 运行中断后输入素材被修改：续跑前校验输入指纹，不一致即拒绝续跑（防"半新半旧"产物）
- 形态配置缺失关键项（如短剧的节奏基准曲线）：启动前拒绝并报错（不静默回退电影配置）
- 两套配置并行运行（不同工作目录）：产物与账目隔离，互不覆盖
- 样片时长超出短剧体量（配置上限）：剪辑门禁按短剧配置判 0（配置生效）
- 全模拟链路的"画质"不可用于对外展示：产物清单与样片元数据**必须标注"模拟生成"**
  （诚实边界，防止被误当作真实作品）

### 关键实体 *（如果功能涉及数据）*

- **形态配置（FormConfig）**: 一套形态的完整参数集（权重/阈值/基准曲线/预算/并行度/规格/外环频率）——`configs/{movie,shortdrama}.yaml`
- **交接契约（HandoffContract）**: 上下游之间的产物 schema 与验收规则（四段：剧本→分镜、分镜→视觉、视觉+声音→剪辑、成片→宣发）
- **试水运行（PilotRun）**: 一次端到端运行的记录——运行 id、配置形态、DAG 节点状态、产物清单、成本账目、状态快照、失败点与原因
- **DAG 节点（PilotStage）**: 一个环节的执行单元——环节名、输入（上游产物引用 + 指纹）、输出（产物引用）、状态（pending/running/done/failed/skipped）
- **可复现样片包（PilotPackage）**: 一次运行的**自包含交付物目录**——成片工件（内容寻址引用 + 时长 + 来源环节链 + **"模拟生成"标注**）+ 各环节关键产物引用 + 产物清单 + 成本账目 + 状态快照
- **成本账目（PilotCostLedger）**: 按环节与形态的成本汇总 + 对账结果
- **升级路径（UpgradePath）**: B/C 的凭证清单、预算口径与切换说明（文档化，可机检字段）

## 假设

- **本特性交付 A 路径（全模拟）**：所有生成走既有确定性模拟器，零凭证、零真实花费；
  成本账目按 Mock 价目估算并如实标注（非真实花费）
