# 阶段 0 调研：短剧形态试水作品（015-pilot-shortdrama）

> 每个决策 = 分歧点 → 备选 → 结论 → 依据。规格：[spec.md](spec.md)（含 2026-09-21 澄清三条）。

## 决策 1：分层——core/orchestration（通用执行器）+ agents/pilot（业务链）

- **结论**：通用 DAG 执行器入 `core/orchestration/`（`dag.py` 拓扑/环检测、`executor.py`
  状态机/断点续跑/输入指纹、`models.py`、`ledger.py` 账目汇总）——**零业务概念**（静态断言）；
  试水链定义、四段交接契约与样片包装配入 `agents/pilot/`（业务侧）
- **依据**：澄清 Q3；宪章原则五（编排属技术栈约束/基建范畴）+ monorepo 边界
  （新增目录须归 core 或 agents，`agents/pilot/` 为业务侧）。

## 决策 2：短剧配置必须"完整可加载"

- **分歧**：`configs/shortdrama.yaml` 要写到多完整？
- **结论**：必须让**全部 Agent 与全部基建模块的配置加载器**通过（各 Agent 的
  `*Config.from_yaml`、replay/pooling/dreaming/calibration/drift/deployment/web 段）
  ——**配置完整性测试**：对 shortdrama.yaml 跑一遍全部加载器，缺项即红；形态差异
  （权重/阈值/基准曲线/预算/规格/外环频率）在此表达
- **依据**：规格 FR-001（缺失关键项启动前报错，不静默回退）；这是"零代码切换"的
  真实检验——若某个加载器要求代码分支才能适配，配置完整性测试就会暴露它。

## 决策 3：四段交接契约——纯映射函数 + 双向快照

- **结论**：`agents/pilot/handoffs.py` 四个纯函数：`script_to_segment`（复用 009
  `export_segment`）、`shotlist_to_gen_params`（每镜景别/时长/风格 → 视觉生成参数）、
  `av_to_edit_inputs`（视觉片段 + 声音工件 → 剪辑镜头库与音轨）、`reel_to_promo_materials`
  （成片 → 宣发物料素材）；每段配**双向快照断言**（上游导出字段集 == 下游输入字段集，
  含枚举值）
- **依据**：规格 FR-003；"各自单测全绿、串起来失败"的集成漂移必须由快照断言拦住。

## 决策 4：环节内重试与终止语义（澄清 Q1 落地）

- **结论**：每环节由该 Agent 的既有 loop 产多候选并择优（既有语义）；候选全不合格
  → 该环节 `failed` → 运行终止；`RunRecord` 记录失败点与**全部候选的判 0 理由**；
  下游环节不启动（不做静默降级）
- **依据**：澄清决议；与各 Agent"一轮多候选"的既有行为一致，不新造重试逻辑。

## 决策 5：断点续跑与输入指纹

- **结论**：`pilot/runs/{run_id}.json`（RunRecord：阶段状态/产物引用/失败原因）文件化；
  续跑前校验**输入指纹** = 素材哈希 + 配置哈希（形态配置与相关 configs）；不一致即
  拒绝续跑（防"半新半旧"产物）；已完成阶段不重跑
- **依据**：规格 FR-006 + 边界情况。

## 决策 6：样片包装配（澄清 Q2 落地）

- **结论**：`agents/pilot/package.py` → `pilot/packages/{run_id}/`：`manifest.json`
  （**"模拟生成"标注** + 形态 + 配置指纹 + 产物清单 + 阶段状态）、`reel.mp4`（引用或
  拷贝）、`products.json`（各环节关键产物引用与哈希）、`cost.json`（账目）、
  `state.json`（评分构成/坍缩/漂移摘要）；一次运行一个包，自包含
- **依据**：澄清决议；作为二期收口的证据载体。

## 决策 7：可复现性

- **结论**：全模拟链路 + 固定种子 + 单线程确定性编码（007/008 既有参数）；同输入同配置
  两次运行：样片与清单逐字节一致；账目一致
- **依据**：规格 SC-001；可复现性是"模拟排练"能作为证据的前提。

## 决策 8：形态分支零代码的机检

- **结论**：静态断言——`core/`、`agents/`（除 `agents/pilot/` 的配置读取）中不得出现
  `shortdrama` 字面量分支或 `form ==` 判断；`configs/shortdrama.yaml` 的存在即是形态
- **依据**：规格 FR-002/SC-002；把"零代码改动"变成可证伪断言。

## 决策 9：升级路径的文档化与机检

- **结论**：`docs/` 下新增升级路径文档（B/C 的凭证清单、预算口径、切换方式），
  并以**结构化清单**（JSON/YAML）承载关键字段（凭证环境变量名、适配器类、切换命令），
  供机检（字段齐全断言）
- **依据**：规格 FR-012；让 A 的产物与真实路径可对照，也为凭证到位后的切换铺路。
