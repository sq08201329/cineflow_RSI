# 契约：试水运行与样片包（agents/pilot）

> 对应规格 US3 / FR-007~010、FR-012。实现：`agents/pilot/{pilot,package}.py`、`ops/pilot.py`。

## C10 一次试水运行

```
run_pilot(form, config_path, inputs, *, data_dir, run_id=None) -> PilotRun（含样片包路径）
```

- 启动前**预检**：输入素材下限、配置完整性（全部加载器可加载）、并行度/预算可用；
  不合格即拒绝（零成本）
- 六阶段按 DAG 执行；各环节走既有门禁与落树；形态全部来自配置（零代码分支）

### 场景

1. 短剧配置一次运行 → 六阶段 done + 样片包产出
2. 同输入同配置两次运行 → 样片与清单逐字节一致（可复现）
3. 输入不足/配置缺项 → 启动前拒绝（零成本、零落树）
4. 代码库静态扫描 → 无形态分支命中（`shortdrama`/`form ==` 字面量在 core/agents 代码中）

## C11 样片包装配

- `pilot/packages/{run_id}/`：manifest（**"模拟生成"标注** + 形态 + 配置指纹 + 产物清单 +
  阶段状态）/ reel / products.json / cost.json / state.json
- 清单与元数据**必须**标注"模拟生成"（诚实边界）

### 场景

1. 装配完成 → 五件套齐备；manifest 含"模拟生成"
2. 缺任一件 → 装配失败（不产半包）

## C12 成本账目对账

- 按 stage/形态汇总 == 各 Agent 落盘成本之和（零差异）；对账失败即报错

### 场景

1. 正常运行 → 零差异；人为篡改 >> 报错

## C13 形态切换与升级路径

- 同链两套配置（movie/shortdrama）运行成功且差异可归因配置（权重/阈值/曲线/预算/规格）
- `docs/` 升级路径文档 + 结构化清单（凭证环境变量名 / 适配器类 / 切换命令 / 预算口径）
  字段齐全（机检）

### 场景

1. 两套配置各跑一轮 → 差异列表与配置项一一对应
2. 升级路径清单字段齐全（含 B/C 的凭证与适配器映射）
