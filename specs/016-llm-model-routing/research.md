# 阶段 0 调研：LLM 模型档案与角色路由（016-llm-model-routing）

> 每个决策 = 分歧点 → 备选 → 结论 → 依据。规格：[spec.md](spec.md)（含 2026-09-22 澄清两条）。

## 决策 1：落点——core/llm_gateway 扩展（业务无关）

- **结论**：`core/llm_gateway/` 新增 `profiles.py`（`ModelProfile` / `RoleRouting` /
  `ProfileSnapshot` 的解析与校验）与 `routing.py`（角色 → 档案解析、默认回落、枚举校验）；
  `gateway.py` 改造为"按角色取档案 → 取后端与价目 → 折算与分解"
- **依据**：原则三（LLM 调用必须经网关）——路由**必须**在网关内；档案/价目是成本口径
  的一部分（原则一），与网关同层。

## 决策 2：角色枚举来源——盘点既有调用点后固定

- **结论**：枚举成员由**现有调用点归纳**并写入代码常量（供配置校验与文档共用）：
  - `generation`：剧本三阶段生成等"内容生成"（screenplay loop）
  - `judge`：各 Agent 的 judge 委员会（004/007/008/009）
  - `dreaming_candidates`：做梦层候选策略生成（005 的 LLMGenerator）
  - `copywriting`：宣发文案生成（003）
- **依据**：澄清 Q1 的固定枚举；不新造角色概念（规格假设）；plan 阶段按代码实际调用点
  再核对一次，若实际更多（如分镜摘要）则扩充枚举并同步文档。

## 决策 3：价目与快照冻结——冻结"档案集合"，不冻结单个模型名

- **结论**：网关暴露 `profile_snapshot()`（档案集合 + 价目 + 价目备注 + 端点 host，
  **不含密钥**），由各 loop 在构造 `config_snapshot` 时并入（键 `llm_profiles`）；
  历史节点因此绑定"当时的价目口径"，改价不污染历史（可审计复算）
- **依据**：规格 FR-002；与既有 `evaluator_weights` 快照同款纪律。

## 决策 4：默认档案——单档案自动认定，多档案强制显式

- **结论**：档案数为 1 → 自动认定为默认并在报告中标注"自动认定"；≥2 → 必须显式声明
  `default_profile`，缺则报错；角色映射为**单层**，出现多层/自指即报错
- **依据**：澄清 Q2；单档案零迁移成本（现状配置即单档案）。

## 决策 5：迁移——旧扁平配置自动映射为单档案

- **结论**：若配置里存在旧写法（`screenplay.model` + `model_prices`，或其它 Agent 的
  `model` + `model_prices`），系统**自动映射**为单档案（档案 id = 模型名，价目取自
  `model_prices`，端点/凭证名取旧环境变量名），并在**启动报告**中列出映射结果与规则
  （明文可见，不做静默兼容）；新写法存在时不读旧键
- **依据**：规格 FR-010 + 假设；避免"配置改了但没人知道走的哪条路"。

## 决策 6：凭证读取与假阳性消除

- **结论**：凭证只按档案声明的 `api_key_env` / `base_url_env` 读取；`HttpBackend` 改为
  **构造入参化**（端点与密钥由路由层注入），**不再隐式读 `OPENAI_*`**（兼容方式 = 在
  档案里显式把变量名写成 `OPENAI_API_KEY`，此时报告标注"沿用旧变量名"）
- **依据**：规格 FR-006/FR-007；本机已发生"平台自带 OPENAI_API_KEY 被误判为就绪"的
  真实假阳性。

## 决策 7：成本分解——网关侧累积，报告层呈现

- **结论**：`BackendResult` 增 `role` / `profile_id` 字段；网关累积
  `cost_breakdown()`（`{role: {profile_id: {tokens, cost_usd}}}`）；**树节点 `CostRecord`
  口径不变**（总成本仍照既有入账），分解数据由 CLI/演示/账目报告呈现
- **依据**：规格 FR-005；不改既有落树口径（避免牵连 6 个 Agent 的成本断言）。

## 决策 8：核查器/冒烟器/清单同步——以配置为权威

- **结论**：`ops/check_credentials.py` 改为**读配置里的档案**（而非模块常量）生成就绪
  矩阵，标注"变量名 + 所属档案 + 用途"；`ops/smoke_llm.py` 的 `--model` 改为
  `--profile`（或两者兼容）；`docs/pilot-upgrade-manifest.json` 的 `credential_envs`
  与配置档案一致性**机检锁**（漂移即红）
- **依据**：规格 FR-008/SC-006；清单与代码/配置三者同源。

## 决策 9：不做的三件事（写进规格，防回潮）

1. **价目不内置**：任何厂商价目都不进代码——码内只有协议实现与路由机制；
2. **不做运行时比价路由**：路由是显式声明（可预测可审计）；
3. **不做两维价目（峰谷/缓存命中）**：以价目备注如实登记局限，待后续特性。
