# Speckit Plan Skill

请根据规格说明和项目宪章，按计划模板（`.specify/templates/plan-template.md`）生成技术实现计划。

**语言要求**：所有输出内容使用中文。

创建步骤：
1. 分析规格说明中的技术需求
2. 确定技术栈和架构方案
3. 按模板结构填写计划
4. 保存到 `specs/[分支名]/plan.md`
