# 二期升级路径：从模拟试水到真实生成与投放

> 功能 015（短剧形态试水作品）T1523 交付；1.1.0 起凭证环境变量名经**凭证核查批次**纠偏
> （以代码为权威）；**1.2.0 起 A → B/C 的切换是"改配置/加两个 CLI 标志"，不再是"改装配代码"**
> （后端选择由形态配置 `pilot` 段驱动，唯一装配点 `agents.pilot.backends::build_backends`）。
> 结构化清单见
> [`pilot-upgrade-manifest.json`](pilot-upgrade-manifest.json)（字段可机检：
> `tests/unit/test_pilot_upgrade_path.py` 逐项断言——凭证环境变量名非空、
> **适配器实现类可导入**、切换命令非空、预算口径键在 `configs/*.yaml` 中存在；
> `tests/unit/test_credential_env_lock.py` 断言**凭证名与适配器代码逐项一致**；
> `tests/unit/test_pilot_backend_selection.py` 断言**后端选择配置驱动 + 空装配点唯一 +
> 缺凭证装配期拒绝 + 清单切换口径与代码一致**）。

## 一、三条路径

| 路径 | 内容 | 凭证（以代码读取点为准） | 状态 |
| --- | --- | --- | --- |
| **A** | 全模拟试水：确定性模拟生成器 + 模拟投放平台，零凭证零外部计费 | 无 | **已交付**（本特性） |
| **B** | 真实视频/音频生成：适配器替换为真实 HTTP 平台 | `OPENAI_BASE_URL` / `OPENAI_API_KEY`（LLM 网关）· `VISUAL_GEN_*` · `STORYBOARD_RENDER_*` · `SOUND_TTS_*` / `SOUND_SFX_*` / `SOUND_MUSIC_*` · `EDIT_RENDER_*`（每组含 `_BASE_URL` + `_API_KEY`，共 14 项） | 未交付（凭证到位后可切换） |
| **C** | 真实投放：宣发适配器替换为真实投放平台，指标经回流管道落树 | `PROMO_PLATFORM_BASE_URL` / `PROMO_PLATFORM_API_KEY`（另需生产库 DSN：`CINEFLOW_PG_DSN`） | 未交付（属运营动作；建立在 B 之上） |

**切换方式（1.2.0）**：装配层按**形态配置 `pilot` 段的取值**决定实现类，五个环节的平台
适配器与 LLM 网关后端都可切；`agents/pilot/stages.py` 里**不再有任何实现类字面量**——
唯一装配点是 `agents/pilot/backends.py` 的 `build_backends`，`build_runtime` 装配一次放进
`PilotRuntime.backends`，各阶段从 runtime 取用。编排链、评估器、门禁与形态配置结构全部不变。

## 一之二、切换怎么写（照抄即可）

```yaml
# 形态配置（configs/*.yaml）里的唯一开关；段缺失即默认值（A 路径零配置可跑）
pilot:
  backend: simulated   # simulated | http —— 五个环节的平台适配器
  llm_backend: mock    # mock | http —— LLM 网关后端
  overrides: {}        # 逐环节覆盖，优先于全局取值：{visual: http, llm: http}
```

```bash
# 一行切换（运行时全局覆盖；不写标志即取配置取值）
uv run python ops/pilot.py run --form shortdrama --config configs/shortdrama.yaml \
    --topic 夜班记录 --minutes 2 --characters 林静,陈默 --data-dir pilot --run-id b-run \
    --backend http --llm-backend http --fixed-clock

# 只切某一环节（生成仍走模拟、仅投放走真实平台）：改配置而非改代码
#   pilot: {backend: simulated, overrides: {promo: http}}
```

**取值优先级**：`pilot.overrides[环节]` > CLI `--backend` / `--llm-backend`（全局覆盖）
> 配置 `pilot.backend` / `pilot.llm_backend` > 默认 `simulated` / `mock`。

**缺凭证的处置（诚实边界）**：声明 `http` 而对应凭证缺失 → **装配期显式失败**
（报错复用该适配器的既有缺凭证文案，**指出缺哪个环境变量**），发生在**落树/生成之前**：
不落树、不扣费、**绝不静默回落模拟**；取值非法（未知环节名或未知取值）同样在装配期拒绝。
`ops/pilot.py precheck` 的输出里含 `pilot_backend` 块（`resolved` 逐环节取值 +
`credentials_checked: false`），**它不验凭证**——凭证面由 `ops/check_credentials.py` 负责。

## 二、凭证与环境变量

**真名表**（每一项都是代码里的真实读取点；清单 `credential_envs` 与之一一对应，机检见 §六）：

| 环节 | 实现类（读取点） | 环境变量 |
| --- | --- | --- |
| LLM（网关 http 后端） | `core.llm_gateway.backends.http.HttpBackend`（构造器直接读，无 `from_env`） | `OPENAI_BASE_URL` / `OPENAI_API_KEY` |
| 视觉 | `agents.visual.platform.http_real.HttpRealVideoGen` | `VISUAL_GEN_BASE_URL` / `VISUAL_GEN_API_KEY` |
| 分镜（预演渲染） | `agents.storyboard.platform.http_real.HttpRealStoryboardRender`（`ENV_PREFIX = "STORYBOARD_RENDER"`） | `STORYBOARD_RENDER_BASE_URL` / `STORYBOARD_RENDER_API_KEY` |
| 声音 | `agents.sound.platform.http_real.HttpRealTTSGen` / `HttpRealSFXGen` / `HttpRealMusicGen`（各自 `ENV_PREFIX`） | `SOUND_TTS_*` / `SOUND_SFX_*` / `SOUND_MUSIC_*`（各含 `_BASE_URL` + `_API_KEY`） |
| 剪辑 | `agents.editing.platform.http_real.HttpRealEditRender`（`ENV_PREFIX = "EDIT_RENDER"`） | `EDIT_RENDER_BASE_URL` / `EDIT_RENDER_API_KEY` |
| 宣发投放 | `agents.promo.platform.http_real.HttpRealPlatform` | `PROMO_PLATFORM_BASE_URL` / `PROMO_PLATFORM_API_KEY` |

- **命名纪律**：不加强制前缀——平台侧怎么命名就怎么登记（旧清单自造的
  `CINEFLOW_VIDEO_*` / `CINEFLOW_AUDIO_*` / `CINEFLOW_PROMO_*` 在代码里**不存在**，
  按它注入会静默无效：真实适配器照样报"缺凭证"）；
- 凭证**只经环境变量注入**，不落盘、不进样片包（与 `web.dsn_env`、`HttpRealPlatform.from_env()` 同纪律）；
- 缺失凭证时的行为：装配期**显式拒绝**（`BackendAssemblyError`，按环节指出缺哪组变量），
  不静默回落到模拟实现（A 路径必须显式声明 `simulated`/缺段默认，见 §一之二）；
- 生产库 DSN：`CINEFLOW_PG_DSN`（回流管道 `ops/ingest_metrics.py --dsn`；非适配器凭证，不入 `credential_envs`）。

## 三、预算口径

- **单轮预算**：各 Agent 段 `exploration_per_round_usd`（剧本段按模型价目表 `model_prices` 计费）；
- **投放门槛**：单轮投放上限 = `promo.exploration_per_round_usd × promo.promo_pilot_ratio`
  （短剧：120 × 0.02 = **$2.4**；电影：500 × 0.02 = $10），超限即**拒投**（不静默超投）；
- **对账**：一次运行的账目按阶段汇总，与各 Agent 落盘成本逐项对账，**零差异**才装配样片包
  （`cost.json` 的 `reconciled: true`；篡改即装配失败）；
- **真实花费**：A 路径为 0（模拟平台零外部计费，成本仍如实入账）；B/C 按平台价目表实扣。

## 四、切换清单（机检字段）

结构化清单 `pilot-upgrade-manifest.json` 的字段口径：

| 字段 | 含义 | 机检 |
| --- | --- | --- |
| `paths[].credential_envs` | 该路径需要的环境变量名清单（**以代码读取点为准**） | 非空字符串、通用命名规范 `^[A-Z][A-Z0-9_]*$`、**与适配器代码逐项一致**（`test_credential_env_lock.py`）、成对（`<PREFIX>_BASE_URL` + `<PREFIX>_API_KEY`）、不得出现自造前缀 `CINEFLOW_` |
| `paths[].adapters` | 该路径使用的适配器实现类（点分路径） | **可导入且类存在**；其读取的 env 名集合即该路径凭证名的权威口径 |
| `paths[].switch_commands` | 切换/运行命令 | 非空、含本仓 CLI（`ops/pilot.py` / `ops/ingest_metrics.py` / `ops/check_credentials.py`）；B/C 各含一条**可照抄的一行切换命令**（`ops/pilot.py run … --backend http`，`test_pilot_backend_selection.py` 断言） |
| `switch_mechanism` | 切换机制（配置段/键、默认值、CLI 标志、唯一装配点、取值优先级、凭证策略，1.2.0 新增） | 装配点**可导入且可调用**、配置键在**两套形态配置中存在**、CLI 标志在 `ops/pilot.py` 中声明、`pilot` 段位于 `deployment` 段之前 |
| `paths[].budget_policy.round_budget_keys` | 预算口径引用的配置键 | **在 `configs/shortdrama.yaml` 中存在** |
| `budget_policy.campaign_cap_formula` | 投放上限公式 | 非空、引用 promo 段两个键 |

## 五、诚实边界

- A 路径产出为**模拟生成**：样片包清单与状态快照均含"模拟生成"标注，**不得作为对外发布素材**；
- 不使用版权素材：夹具与全部生成内容均为合成（程序化帧/波形/伪文本）；
- B/C 未交付，本文档只登记"切换方式与凭证清单"，**不代表真实链路已验证**；
- **切换是配置动作**（1.2.0）：`pilot` 段取值 + 两个 CLI 标志即可切；声明真实后端而凭证缺失
  在装配期显式失败（指出缺哪个环境变量、零落树零扣费），**不回落模拟**——不假装跑过真实链路；
- 真实投放属运营动作，需人工确认账户与预算，且不得由自动进化路径触发；
- 凭证名以**代码**为权威（1.1.0 纠偏）：旧清单的 `CINEFLOW_*` 前缀系自造，代码从未读取；
- 探测只走只读端点：`--probe` 绝不触发任何付费生成调用；
- **装配成功 ≠ 链路可用**：本期真实适配器的业务方法仍是骨架（`estimate` / `generate` /
  `render` / `submit` 一律 `UnavailableError: …本期未接入`），故"B/C 未交付"的登记不变——
  切换开关只是把"改装配代码"变成"改配置"，**不假装真实链路已跑通**；
- **响度标定仍用模拟合成器**（遗留）：声音阶段的 `loudness_gain_db` 由模拟声源合成后反推，
  切 `sound: http` 后该标定口径仍取自 `sound.simulated_gen`——真实声音平台的标定方式
  属实现变更加版本，路径不变。

## 六、凭证核查

### 一条命令判断凭证是否可用

```bash
uv run python ops/check_credentials.py                 # 零网络：就绪矩阵（缺什么、已有什么）
uv run python ops/check_credentials.py --probe         # 加只读连通性/鉴权探测
uv run python ops/check_credentials.py --probe --path B
```

- **退出码**：`0` 全就绪｜`1` 有缺失或探测未通过（便于脚本化门禁）｜`2` 用法/清单错误；
- **输出**：每条路径的 `runnable`、`present` / `missing`（按清单登记顺序）、`blocked_by`、
  `next_steps`（每项缺失的最小验证方式）、`summary.runnable` / `summary.blocked`；
- **A 恒为可跑**：零凭证基线（全模拟链路零外部计费），核查器显式标注 `zero_credential_baseline`；
- 目前无凭证环境下实测输出：A 可跑、B/C 缺全部凭证（B 14 项 + C 2 项），退出码 **1**。

### 每项的最小验证方式

"构造即验证"——适配器缺凭证必报错（不静默回落模拟），因此成功构造即凭证可用：

| 凭证 | 最小验证（无输出即通过） |
| --- | --- |
| `OPENAI_*` | `uv run python -c "from core.llm_gateway.backends.http import HttpBackend; HttpBackend()"` |
| `VISUAL_GEN_*` | `uv run python -c "from agents.visual.platform.http_real import HttpRealVideoGen; HttpRealVideoGen.from_env()"` |
| `STORYBOARD_RENDER_*` | `uv run python -c "from agents.storyboard.platform.http_real import HttpRealStoryboardRender; HttpRealStoryboardRender.from_env()"` |
| `SOUND_TTS_*` / `SOUND_SFX_*` / `SOUND_MUSIC_*` | 同目录 `HttpRealTTSGen.from_env()` / `HttpRealSFXGen.from_env()` / `HttpRealMusicGen.from_env()` |
| `EDIT_RENDER_*` | `uv run python -c "from agents.editing.platform.http_real import HttpRealEditRender; HttpRealEditRender.from_env()"` |
| `PROMO_PLATFORM_*` | `uv run python -c "from agents.promo.platform.http_real import HttpRealPlatform; HttpRealPlatform.from_env()"`（生产回流链路 `ops/ingest_metrics.py` 亦会构造它，缺凭证即报错退出） |

上表由核查器逐项写进 `next_steps[].verify`（**从清单登记的适配器类生成，不手抄**；
`test_credential_env_lock.py` 反向校验提示里的类真的读那组 env）。

### 探测失败的两类区分（处置动作不同）

| 状态 | 含义 | 处置 |
| --- | --- | --- |
| `missing` | 环境**未注入**该组凭证（不发任何请求） | 注入凭证后重跑 `--probe` |
| `auth_rejected` | 已注入但**鉴权被拒**（HTTP 401/403） | 换密钥/开权限（不是网络问题） |
| `unreachable` | 已注入但**连不通**（DNS/连接/超时） | 查网络/代理/基址（不是凭证问题） |
| `server_error` | 已连通但平台报 5xx | 平台侧故障，等恢复 |
| `path_unknown` / `http_other` | 已连通但探测路径未命中（404/405）或平台返回其他 4xx | **不阻断**：如实标为"鉴权未验证"，用 `--probe-path PREFIX=/真实路径` 复核 |

### 哪些探测不花钱（零计费清单）

- 核查器**默认零网络调用**（只读环境变量与清单），可随意重跑；
- `--probe` 只发 **GET** 到登记只读端点（LLM `/models`；其余默认 `/health`，可覆盖）——**零生成、零计费**；
- `uv run python ops/pilot.py precheck ...`：零成本零落树（只验配置完整性 18 个加载器；
  **注意：它不验凭证**，凭证面由本核查器负责）；
- A 路径 `uv run python ops/pilot.py run ...`（模拟链路）：零外部计费（成本仍如实入账）；
- **禁止**：对生成/投放端点发 POST"试一下"——核查器没有这条代码路径（
  `test_credential_env_lock.py::test_探测一律为只读_GET_且不指向生成端点` 把它钉死）。
