## 一之二、切换怎么写（照抄即可）

```yaml
# 形态配置（configs/*.yaml）里的唯一开关；段缺失即默认值（A 路径零配置可跑）
pilot:
  backend: simulated   # simulated | http —— 五个环节的平台适配器
  llm_backend: mock    # mock | http —— LLM 网关后端
  overrides: {}        # 逐环节覆盖，优先于全局取值：{visual: http, llm: http}
```

```bash
# 一行切换（运行时全局覆盖；不写标志即取配置取值）
uv run python ops/pilot.py run --form shortdrama --config configs/shortdrama.yaml \
    --topic 夜班记录 --minutes 2 --characters 林静,陈默 --data-dir pilot --run-id b-run \
    --backend http --llm-backend http --fixed-clock

# 只切某一环节（生成仍走模拟、仅投放走真实平台）：改配置而非改代码
#   pilot: {backend: simulated, overrides: {promo: http}}
```

**取值优先级**：`pilot.overrides[环节]` > CLI `--backend` / `--llm-backend`（全局覆盖）
> 配置 `pilot.backend` / `pilot.llm_backend` > 默认 `simulated` / `mock`。

**缺凭证的处置（诚实边界）**：声明 `http` 而对应凭证缺失 → **装配期显式失败**
（报错复用该适配器的既有缺凭证文案，**指出缺哪个环境变量**），发生在**落树/生成之前**：
不落树、不扣费、**绝不静默回落模拟**；取值非法（未知环节名或未知取值）同样在装配期拒绝。
`ops/pilot.py precheck` 的输出里含 `pilot_backend` 块（`resolved` 逐环节取值 +
`credentials_checked: false`），**它不验凭证**——凭证面由 `ops/check_credentials.py` 负责。

## 二、凭证与环境变量

**真名表**（每一项都是代码里的真实读取点；清单 `credential_envs` 与之一一对应，机检见 §六）：

| 环节 | 实现类（读取点） | 环境变量 |
| --- | --- | --- |
| LLM（网关 http 后端） | `core.llm_gateway.backends.http.HttpBackend`（构造器直接读，无 `from_env`） | `OPENAI_BASE_URL` / `OPENAI_API_KEY` |
| 视觉 | `agents.visual.platform.http_real.HttpRealVideoGen` | `VISUAL_GEN_BASE_URL` / `VISUAL_GEN_API_KEY` |
| 分镜（预演渲染） | `agents.storyboard.platform.http_real.HttpRealStoryboardRender`（`ENV_PREFIX = "STORYBOARD_RENDER"`） | `STORYBOARD_RENDER_BASE_URL` / `STORYBOARD_RENDER_API_KEY` |
| 声音 | `agents.sound.platform.http_real.HttpRealTTSGen` / `HttpRealSFXGen` / `HttpRealMusicGen`（各自 `ENV_PREFIX`） | `SOUND_TTS_*` / `SOUND_SFX_*` / `SOUND_MUSIC_*`（各含 `_BASE_URL` + `_API_KEY`） |
| 剪辑 | `agents.editing.platform.http_real.HttpRealEditRender`（`ENV_PREFIX = "EDIT_RENDER"`） | `EDIT_RENDER_BASE_URL` / `EDIT_RENDER_API_KEY` |
| 宣发投放 | `agents.promo.platform.http_real.HttpRealPlatform` | `PROMO_PLATFORM_BASE_URL` / `PROMO_PLATFORM_API_KEY` |

- **命名纪律**：不加强制前缀——平台侧怎么命名就怎么登记（旧清单自造的
  `CINEFLOW_VIDEO_*` / `CINEFLOW_AUDIO_*` / `CINEFLOW_PROMO_*` 在代码里**不存在**，
  按它注入会静默无效：真实适配器照样报"缺凭证"）；
- 凭证**只经环境变量注入**，不落盘、不进样片包（与 `web.dsn_env`、`HttpRealPlatform.from_env()` 同纪律）；
- 缺失凭证时的行为：装配期**显式拒绝**（`BackendAssemblyError`，按环节指出缺哪组变量），
  不静默回落到模拟实现（A 路径必须显式声明 `simulated`/缺段默认，见 §一之二）；
- 生产库 DSN：`CINEFLOW_PG_DSN`（回流管道 `ops/ingest_metrics.py --dsn`；非适配器凭证，不入 `credential_envs`）。

## 二之二、B/C 路径协议实现与本地 stub 验证（1.3.0 → 1.4.0 全部适配器族）

**全部真实适配器族已不是骨架**（视觉生成 / 分镜预演 / 声音 ×3 / 剪辑渲染 / 宣发投放 /
LLM 网关 http 后端）：接口语义（请求形态 + 错误映射 + 成本/token 纪律）钉死在
`core/platform_http.py` 的模块 docstring（LLM 走 `core/llm_gateway/backends/http.py` 的
OpenAI 兼容口径），各适配器共用同一套客户端。逐个端点如下：

| 端点 | 语义 |
| --- | --- |
| `POST {base}/jobs` | `{"params": …, "idempotency_key": …}` → `202 {"external_id", "estimated_cost_usd", "status"}`；**同幂等键重复提交必须返回同一 `external_id`**（去重语义在平台侧，适配器不自行编造） |
| `POST {base}/estimate` | 只读估价 → `{"estimated_cost_usd"}`（预算门禁的校验依据；不建任务不计费） |
| `GET {base}/jobs/{id}` | `{"status": "pending\|running\|succeeded\|failed", "estimated_cost_usd", "actual_cost_usd", "error"}`（`actual` 为 `null` 即尚未扣费） |
| `GET {base}/jobs/{id}/artifact` | 二进制体（视觉/分镜/剪辑为 **mp4 原样**、声音为 **wav 原样**）+ `X-Artifact-Meta: base64(JSON)`（工件元数据；声音必含 `loudness_gain_db` + 类型标记）；未就绪 → 409 |
| `POST {base}/jobs/{id}/cancel` | 取消（已完成/已失败为无操作） |
| `GET {base}/health` | 只读探测端点（与 §六 的 `PROBE_PATHS` 口径一致） |
| `POST {base}/campaigns` · `GET {base}/campaigns/{id}` · `GET {base}/campaigns/{id}/metrics` · `POST {base}/campaigns/{id}/pause` | 宣发投放：创建/状态/指标/暂停；**指标未就绪 → 409 → `MetricsNotReadyError`（绝不返 0）**，指标越界经 `validate_metrics` 拒为 `MetricValidationError`，`spent_usd > budget_usd` 显式报错 |
| `POST {base}/chat/completions`（OpenAI 兼容） | LLM：`choices[0].message.content` + `usage{prompt_tokens, completion_tokens}` **一律以响应为准**（不本地估算 token）；usage 缺失即报错（不允许静默按 0 计费），成本由网关按 `price_book` 折算 |

**声音环节**（TTS/SFX/音乐）：工件是 **wav 原样字节**，声学属性元数据（`loudness_gain_db` +
类型标记 `cer_injected` / `event_times_ms` / `emotion_vector`）经 `X-Artifact-Meta` 承载、
缺失即拒；请求参数 = 调用方 params + **类属性 `gen_type`**（三类型各自适配器，类型不交给调用方传错）。

**LLM 后端错误映射**（`HttpBackend`）：5xx/连接失败/超时 → `TransientBackendError`；
**429 限流也归瞬态**（对既有"4xx 不重试"的一处显式例外：限流是瞬态，网关的指数退避正是对策）；
其余 4xx（含 401/403）→ `PermanentBackendError`；响应不可解析/缺 usage → 瞬态错误 + 响应片段。
缓存与重试仍由网关承载（后端只发一次请求，防双层重试叠加）。
**错误映射**（不泄漏 `urllib`/`socket` 异常类型，文案含截断的响应片段便于诊断）：
429 → `RateLimitedError`；409 → 工件未就绪/状态冲突；其余 4xx（含 401/403 鉴权被拒）→
参数类错误（视觉 `InvalidParamsError`、渲染 `RenderError`）；5xx / 连接失败 / 请求超时 /
响应不可解析 → `UnavailableError`（超时文案注明超时值）。

**成本纪律**：预估与实际都**以平台响应为准**（本地零估算）；`actual > estimated` 显式报错
（账目异常，拒绝入账，不静默接受）；实际扣费在取件后查询（"取件即入账"时序）。

**超时**：构造参数注入（`request_timeout_s` 默认 30s；渲染环节另有 `poll_interval_s`
默认 1s 与 `poll_deadline_s` 默认 300s），都归 `UnavailableError` 并注明——
不把"没等到"当成"任务失败"（任务可能仍在平台侧执行）。

**本地验证形态（零凭证、零外部网络）**：

```bash
# ① 全部适配器族的协议端到端（本地 loopback stub，54 条：三环节 31 + 声音/宣发 23）
uv run pytest tests/integration/test_http_real_stub.py -q
#    另：LLM 后端契约 8 条（同 stub 驱动）
uv run pytest tests/contract/test_llm_http_backend.py -q

# ② 让既有契约套件的"真实实现分支"在 stub 上全族实跑（默认不启用：无凭证照旧 skip）
CINEFLOW_CONTRACT_STUB=1 uv run pytest tests/contract -q   # → 309 passed
```

stub 的"生成/渲染侧"**按规范化参数自行产出**（分镜走 `board_render.render_animatic`、剪辑走
`SimulatedEditRenderer`、视觉走 `encode_mp4(render_frames(...))`、声音走
`audio.synthesize_wav`）：契约套件传什么输入就产什么真实 mp4/wav 与元数据，
故 ffprobe 规格 / 元数据键 / 逐字节确定性 / 指标 schema 等断言是被**真验证**的。

**真实厂商对接仍需做什么**（属配置或小改，不是重写）：

1. 按厂商 API 调整路径与字段名（如估价/状态端点命名、元数据放 JSON 体或另立查询端点）；
2. 按厂商鉴权方式调整 `Authorization` 头（现为 `Bearer <key>`）；
3. 状态机/枚举取值若与协议不同（如厂商另设 `cancelled`/`queued`、指标用千分比），
   在适配器的映射表登记——未登记状态一律报错，不静默猜；
4. 规格承载口径：分镜/视觉/声音的规格随调用注入（`params`，适配器原样透传）；
   **剪辑环节的渲染规格由平台侧配置承载**（接口签名无 cfg 注入点）；宣发的
   `distribution` 只做签名兼容、绝不外发（见 §五）；
5. 声音的**注入标记**（错字率/事件时间/情绪向量）须由平台回传或按其真实质量指标映射；
6. LLM 接入按厂商兼容层调整（OpenAI 兼容即零改动；非兼容需换后端实现，网关与计费口径不变）。

## 三、预算口径

- **单轮预算**：各 Agent 段 `exploration_per_round_usd`（剧本段按模型价目表 `model_prices` 计费）；
- **投放门槛**：单轮投放上限 = `promo.exploration_per_round_usd × promo.promo_pilot_ratio`
  （短剧：120 × 0.02 = **$2.4**；电影：500 × 0.02 = $10），超限即**拒投**（不静默超投）；
- **对账**：一次运行的账目按阶段汇总，与各 Agent 落盘成本逐项对账，**零差异**才装配样片包
  （`cost.json` 的 `reconciled: true`；篡改即装配失败）；
- **真实花费**：A 路径为 0（模拟平台零外部计费，成本仍如实入账）；B/C 按平台价目表实扣。

## 四、切换清单（机检字段）

结构化清单 `pilot-upgrade-manifest.json` 的字段口径：

| 字段 | 含义 | 机检 |
| --- | --- | --- |
| `paths[].credential_envs` | 该路径需要的环境变量名清单（**以代码读取点为准**） | 非空字符串、通用命名规范 `^[A-Z][A-Z0-9_]*$`、**与适配器代码逐项一致**（`test_credential_env_lock.py`）、成对（`<PREFIX>_BASE_URL` + `<PREFIX>_API_KEY`）、不得出现自造前缀 `CINEFLOW_` |
| `paths[].adapters` | 该路径使用的适配器实现类（点分路径） | **可导入且类存在**；其读取的 env 名集合即该路径凭证名的权威口径 |
| `paths[].switch_commands` | 切换/运行命令 | 非空、含本仓 CLI（`ops/pilot.py` / `ops/ingest_metrics.py` / `ops/check_credentials.py`）；B/C 各含一条**可照抄的一行切换命令**（`ops/pilot.py run … --backend http`，`test_pilot_backend_selection.py` 断言） |
| `switch_mechanism` | 切换机制（配置段/键、默认值、CLI 标志、唯一装配点、取值优先级、凭证策略，1.2.0 新增） | 装配点**可导入且可调用**、配置键在**两套形态配置中存在**、CLI 标志在 `ops/pilot.py` 中声明、`pilot` 段位于 `deployment` 段之前 |
| `paths[].budget_policy.round_budget_keys` | 预算口径引用的配置键 | **在 `configs/shortdrama.yaml` 中存在** |
| `budget_policy.campaign_cap_formula` | 投放上限公式 | 非空、引用 promo 段两个键 |

## 五、诚实边界

- A 路径产出为**模拟生成**：样片包清单与状态快照均含"模拟生成"标注，**不得作为对外发布素材**；
- 不使用版权素材：夹具与全部生成内容均为合成（程序化帧/波形/伪文本）；
- B/C 未交付，本文档只登记"切换方式与凭证清单"，**不代表真实链路已验证**；
- **切换是配置动作**（1.2.0）：`pilot` 段取值 + 两个 CLI 标志即可切；声明真实后端而凭证缺失
  在装配期显式失败（指出缺哪个环境变量、零落树零扣费），**不回落模拟**——不假装跑过真实链路；
- 真实投放属运营动作，需人工确认账户与预算，且不得由自动进化路径触发；
- 凭证名以**代码**为权威（1.1.0 纠偏）：旧清单的 `CINEFLOW_*` 前缀系自造，代码从未读取；
- 探测只走只读端点：`--probe` 绝不触发任何付费生成调用；
- **协议实现 ≠ 厂商对接**（1.3.0 → 1.4.0 覆盖全部适配器族）：视觉/分镜/声音×3/剪辑/宣发/LLM
  的适配器已实现协议语义（幂等键透传、错误映射、成本与 token 以响应为准、超时归不可用、
  指标未就绪如实报错），并由**本地 stub** 端到端验证（零凭证、零外部网络）；
  **"能连 stub"不等于"B/C 路径已验证"**——真实厂商的路径/鉴权/字段与真实计费均未跑过，
  故"B/C 未交付"的登记不变；装配成功仍不等于链路可用；
- **剪辑与分镜/视觉的规格注入口径不同**（遗留）：分镜/视觉把渲染规格随调用注入 `params`，
  而剪辑环节的接口签名（C10）只给 `edl` 与 `shots`，规格由平台侧配置承载——真实接入时
  若需"规格随调用注入"，属**接口变更**（加版本），不是适配器内部改法；
- **响度标定与真实后端不兼容 → 如实拒绝**（1.4.0 修复既有遗留）：声音阶段的
  `loudness_gain_db` 由**模拟**合成器合成一遍波形测响度后反推增益（`build_sound_plans`
  的 `_calibrated_params`），该口径只在 `sound` 后端为 `simulated` 时成立；切 `sound: http`
  后 `build_sound_plans` 直接抛 `StageFailedError`（**零生成零扣费**、不落树），报错里写明
  原因与两条替代做法——① 把目标响度作为参数下传、由平台侧按其规范保证（适配器已原样透传
  `params`，无需改协议）；② 两段式真实标定（先真实生成 → 实测 → 二次生成，**会真实扣费两次**）。
  选"如实拒绝"而非"改走真实测量"的理由：真实测量要额外付费且会改变声音阶段的计费结构，
  属实现变动，须先评估计费再接入（见 `tests/unit/test_pilot_sound_calibration.py` 的机检）；
- **宣发 `distribution` 不接线**（1.4.0）：`HttpRealPlatform(base_url, api_key, distribution)`
  的 `distribution` 是**模拟平台**的指标生成分布；真实平台的指标是平台真值，**既不外发也不本地推算**，
  保留入参只为不破坏既有装配点与契约夹具签名（真实指标一律取自 `/campaigns/{id}/metrics`）。

## 六、凭证核查

### 一条命令判断凭证是否可用

```bash
uv run python ops/check_credentials.py                 # 零网络：就绪矩阵（缺什么、已有什么）
uv run python ops/check_credentials.py --probe         # 加只读连通性/鉴权探测
uv run python ops/check_credentials.py --probe --path B
```

- **退出码**：`0` 全就绪｜`1` 有缺失或探测未通过（便于脚本化门禁）｜`2` 用法/清单错误；
- **输出**：每条路径的 `runnable`、`present` / `missing`（按清单登记顺序）、`blocked_by`、
  `next_steps`（每项缺失的最小验证方式）、`summary.runnable` / `summary.blocked`；
- **A 恒为可跑**：零凭证基线（全模拟链路零外部计费），核查器显式标注 `zero_credential_baseline`；
- 目前无凭证环境下实测输出：A 可跑、B/C 缺全部凭证（B 14 项 + C 2 项），退出码 **1**。

### 每项的最小验证方式

"构造即验证"——适配器缺凭证必报错（不静默回落模拟），因此成功构造即凭证可用：

| 凭证 | 最小验证（无输出即通过） |
| --- | --- |
| `OPENAI_*` | `uv run python -c "from core.llm_gateway.backends.http import HttpBackend; HttpBackend()"` |
| `VISUAL_GEN_*` | `uv run python -c "from agents.visual.platform.http_real import HttpRealVideoGen; HttpRealVideoGen.from_env()"` |
| `STORYBOARD_RENDER_*` | `uv run python -c "from agents.storyboard.platform.http_real import HttpRealStoryboardRender; HttpRealStoryboardRender.from_env()"` |
| `SOUND_TTS_*` / `SOUND_SFX_*` / `SOUND_MUSIC_*` | 同目录 `HttpRealTTSGen.from_env()` / `HttpRealSFXGen.from_env()` / `HttpRealMusicGen.from_env()` |
| `EDIT_RENDER_*` | `uv run python -c "from agents.editing.platform.http_real import HttpRealEditRender; HttpRealEditRender.from_env()"` |
| `PROMO_PLATFORM_*` | `uv run python -c "from agents.promo.platform.http_real import HttpRealPlatform; HttpRealPlatform.from_env()"`（生产回流链路 `ops/ingest_metrics.py` 亦会构造它，缺凭证即报错退出） |

上表由核查器逐项写进 `next_steps[].verify`（**从清单登记的适配器类生成，不手抄**；
`test_credential_env_lock.py` 反向校验提示里的类真的读那组 env）。

### 探测失败的两类区分（处置动作不同）

| 状态 | 含义 | 处置 |
| --- | --- | --- |
| `missing` | 环境**未注入**该组凭证（不发任何请求） | 注入凭证后重跑 `--probe` |
| `auth_rejected` | 已注入但**鉴权被拒**（HTTP 401/403） | 换密钥/开权限（不是网络问题） |
| `unreachable` | 已注入但**连不通**（DNS/连接/超时） | 查网络/代理/基址（不是凭证问题） |
| `server_error` | 已连通但平台报 5xx | 平台侧故障，等恢复 |
| `path_unknown` / `http_other` | 已连通但探测路径未命中（404/405）或平台返回其他 4xx | **不阻断**：如实标为"鉴权未验证"，用 `--probe-path PREFIX=/真实路径` 复核 |

### 哪些探测不花钱（零计费清单）

- 核查器**默认零网络调用**（只读环境变量与清单），可随意重跑；
- `--probe` 只发 **GET** 到登记只读端点（LLM `/models`；其余默认 `/health`，可覆盖）——**零生成、零计费**；
- `uv run python ops/pilot.py precheck ...`：零成本零落树（只验配置完整性 18 个加载器；
  **注意：它不验凭证**，凭证面由本核查器负责）；
- A 路径 `uv run python ops/pilot.py run ...`（模拟链路）：零外部计费（成本仍如实入账）；
- **禁止**：对生成/投放端点发 POST"试一下"——核查器没有这条代码路径（
  `test_credential_env_lock.py::test_探测一律为只读_GET_且不指向生成端点` 把它钉死）。

## 七、真实 LLM 冒烟（按模型档案 / 角色，1.5.0 → 1.6.0）

**只有 LLM 凭证**（`OPENAI_BASE_URL` + `OPENAI_API_KEY`，OpenAI 兼容）时，用
`ops/smoke_llm.py` 验证 LLM 腿——**其余适配器仍无凭证，视觉/分镜/声音/剪辑/宣发的平台侧
保持模拟，C 路径与真实生成仍 `not_delivered`**。

### 7.1 命令（在**你自己的 shell** 里执行；本仓任何文件都不含真实密钥）

```bash
export OPENAI_API_KEY=...        # 你的密钥（本仓任何文件都不含真实密钥；脚本只报"已设置 + 长度"）

# ⓪ 先看档案化就绪矩阵（零网络）：变量名 / 所属档案 / 用途 / 端点，未被子档案声明的变量会被忽略
uv run python ops/check_credentials.py                 # 加 --probe-profiles 才探档案端点（只读 /health）

# ① 网关级冒烟：**按档案**调用一次（--model 为等价别名，冲突即拒）
uv run python ops/smoke_llm.py --profile deepseek-flash

# ② 最小规模的真实试水单轮（**会真的计费**）：改写 llm.roles 把四角色指向该档案
uv run python ops/smoke_llm.py --config configs/shortdrama.yaml --profile deepseek-flash --round

# ③ 零真实调用的装配校验（同一最小档，LLM 走 mock，不需要凭证）
uv run python ops/smoke_llm.py --config configs/shortdrama.yaml --profile deepseek-flash --round --dry-run
```

**档案与角色（功能 016）**：端点/凭证变量名/价目写在 `llm.profiles`，角色映射写在 `llm.roles`
（`generation`/`judge`/`copywriting`/`dreaming_candidates` 四个固定角色）；`--profile` 指定要冒烟的
档案；`--round` 只改**角色映射**（不再散落改模型名）。**价目为何不内置进代码**：价目内置即历史
成本不可复现（原则一）——档案与价目随 `config_snapshot["llm_profiles"]` 冻结进树，
改价只影响新节点（`tests/unit/test_llm_price_freeze.py` 机检可证伪）。

- **退出码**：`0` 成功｜`1` 凭证缺失（指向 `ops/check_credentials.py --probe --path B`）｜`2` 其它失败；
- **隐私**：脚本只打印凭证"已设置/未设置 + 长度"，base 只打印 `scheme://host[:port]`
  （不含路径/查询串/密钥）；`--round` 的临时配置与运行数据放在 `--work-dir`（默认 `.smoke-llm`，
  已入 `.gitignore`，成功后自动清理，`--keep-work-dir` 可保留）。

### 7.2 价目口径（真实计费的唯一依据）

`configs/*.yaml` 的 `screenplay.model_prices`（网关价目表的唯一来源；`promo.model_prices` 同步登记）
新增两条，按**峰时（UTC 周一至周五 01:00–04:00 / 06:00–10:00）缓存未命中上限**折算成每 1k tokens：

| 模型 | 输入（$/1k） | 输出（$/1k） | 官方口径（$/1M） |
| --- | --- | --- | --- |
| `deepseek-flash` | 0.0003 | 0.0012 | 输入 0.3（峰时）/0.15（错峰）；输出 1.2/0.6 |
| `deepseek-v4-pro` | 0.00132 | 0.00396 | 输入 1.32/0.66；输出 3.96/1.98 |

- **保守高估**：取峰时 + 缓存未命中（真实账单因缓存命中与错峰计价只会更低）——
  峰谷与缓存命中率**无法在单一费率表里表达**，属**已登记的估算限制**；
- 既有 `mock-copy-v1` 保留（A 路径与全部测试不受影响）；模型名/价目变动由运维按官方口径更新
  （旧名 `deepseek-chat` 等已退役，不在表内）。

### 7.3 只切 LLM 后哪些环节变真实

| 环节 | 切 `llm_backend: http` 后 | 说明 |
| --- | --- | --- |
| 剧本线（生成 + judge） | **真实 LLM** | 三阶段生成与 `judge.dramatic_tension` 委员会都过网关 |
| 分镜 / 视觉 / 剪辑的 judge | **真实 LLM** | LLM judge 走同一网关；其**平台侧（渲染/生成）仍是模拟** |
| 宣发文案生成 | **真实 LLM** | 物料文案由网关生成；**投放平台仍是模拟**（C 路径需 `PROMO_PLATFORM_*`） |
| 声音标定 / 声音生成 | 保持模拟 | 响度标定在真实后端下**如实拒绝**（见 §五）；声音生成需 `SOUND_*` 凭证 |

### 7.4 `--round` 的最小规模与成本量级（**估算**）

`--round` 用 `core.yaml_edit` 定点改写临时配置（注释逐字保留）：把所有模型引用
（`screenplay.model`、`screenplay.judge.model`、`storyboard.judge.model`、`promo.default_model`）
换成 `--model`，把规模压到最小（**镜头数 = 4**、各环节单轮组合数 1、单轮预算下调），
并在 `pilot` 段声明 `llm_backend`。**预算门禁等机制不变**（只改取值、不改机制）。

实测（`--round --dry-run`，模拟后端）：**48 次 LLM 调用**、prompt ≈ **39k tokens**、
completion **千 token 量级**（模拟后端的补全文本很短，真实模型会显著更长）。据此按上表折算：

| 档位 | 粗略量级 |
| --- | --- |
| `deepseek-flash` | **≈ $0.02**（prompt $0.012 + completion 千 token 级） |
| `deepseek-v4-pro` | **≈ $0.1** |

**这是估算**：真实 token 数取决于提示词与补全长度（剧本三阶段的 JSON 补全会明显大于模拟值），
按 2~5 倍余量准备即可（flash 仍 < $0.1、pro 仍 < $0.5）。**平台侧金额（视觉/声音/剪辑/宣发的
账面成本）在 `--round` 里是模拟平台的成本，零外部计费**，真实账单只来自 LLM。
