## 1. 立项背景

二期已收口（见 `docs/二期交付总览.md`）：六个 Agent 闭环（宣发/视觉/声音/剪辑/分镜/剧本）、
四项基建（跨项目池化/漂移检测/只读前端/部署评估自动化）、短剧形态 A 路径试水端到端跑通。
三期立项前又完成两件关键准备：

1. **真实 LLM 链路已打通并验证**（功能 016 + 真实 DeepSeek 调用）：档案化配置 + 角色路由 +
   价目随快照冻结；真实单轮六阶段全 `done`，真实花费 $0.042（其余为模拟平台账面成本）。
   真实接入过程暴露并修掉 6 个 bug（含**剧本阶段门禁自 015 起从未生效**这类致命缺陷）——
   证明"真实调用才能发现的问题"必须在阶段三成为常规动作。
2. **二期遗留被清晰登记**（二期交付总览 §8）：影子期与部署自动化转正、B/C 路径、
   账单对账、基准标定、运营数据积累。

技术方案 §5.2 阶段三的三条主线：**七 Agent 全链路跑通一部电影长片**、**剧本 Agent 是否
升级自动进化（视 judge 信号质量）**、**以配置化评估器插件接入短剧/广告形态**。

## 2. 三期定位与目标

**定位**：从"六个环节各自闭环 + 单形态排练"走到"**七 Agent 全链路 + 真实渠道 + 多形态**"——
即从"系统能跑"到"系统在真实商业反馈下自我改进"。

**北极星指标（承接技术方案 §5.3，阶段三目标值）**

| 指标 | 二期出口 | 三期目标 |
| --- | --- | --- |
| 进化增益 | 各 Agent 首轮曲线（演示规模） | 真实运营节奏下持续 >1；至少一个 Agent 的进化结论被真实反馈证实 |
| 算力杠杆比 | 成本入账体系 + 真实 LLM 计费验证 | **≥50×**（阶段一 ≥10× 已具备，需真实对账支撑） |
| 评估器信度 | 010 周校准 + 012 漂移监控就绪 | 核心环节内环得分与真实商业结果相关 ≥0.6，或诚实记录未达 |
| 单项目边际成本 | 试水作品 A 路径成本账目 | 电影长片链路跑通并给出首份边际成本对比 |

## 3. 范围

### 3.1 In Scope（三个工作流）

**WS1 七 Agent 全链路（技术方案阶段三主线）**

| # | 特性（拟 specs 编号） | 内容 | 关键验收 |
| --- | --- | --- | --- |
| G1 | `017-dev-agent-degraded` | 开发 Agent（选题/IP 评估）以**降级模式**接入：记录-回放 + 人工策略 + 回放沙盘；复用 009 的降级骨架与判据材料机制；**不做自动进化**（宪章原则六既定） | 选题树全量落盘可回放；禁止自动进化三重机检；回放对比报告可产出 |
| G2 | `018-feature-film-pipeline` | **电影长片全链路编排**：七 Agent 串链（开发→剧本→分镜→视觉→声音→剪辑→宣发），在**真实渠道**下跑通一部长片体量项目（时长/规模按形态配置）；跨环节交接契约扩展（017 的选题产出 → 剧本输入） | 七环节全链路产出可复现样片包 + 全链路成本账目 + 各环评估分量；长片体量的性能与预算门禁达标 |
| G3 | `019-real-channel-billing` | **真实渠道与账单对账**：B/C 路径真实适配器对接（按厂商校准协议假设）+ 厂商账单导入与对账（网关记账 vs 实际账单的差异报告）+ 两维价目（峰谷/缓存命中）表达 | 至少一条真实渠道连续运行 ≥1 周；账单对账差异可解释（口径备注与实测偏差）；两维价目可表达 |

**WS2 多形态扩展（技术方案阶段三）**

| # | 特性（拟 specs 编号） | 内容 | 关键验收 |
| --- | --- | --- | --- |
| G4 | `020-shortdrama-real-feedback` | **短剧形态的真实投放与日级回流**（C 路径）：平台凭证接入、日级指标回流、外环频率日级运转 | 短剧线真实数据回流 ≥2 周；评估器校准结论按迁移思路回灌电影线 |
| G5 | `021-form-plugin-validation` | **形态插件扩展性验证**：广告/漫剧形态以配置化评估器插件接入（零代码改动验证） | 新形态接入 = 仅新增配置 + 评估器插件；静态断言无形态分支 |

**WS3 治理转正与遗留收口**

1. **部署自动化转正**（014 遗留）：影子模式真实运行 ≥2 周 → 误入率标定 → 开启 `auto` 模式；
   抽检与回滚流程在真实运营中检验；
2. **剧本 Agent 升级决议**（治理事项，非特性）：010/012 积累的判据材料若达标 → 另立决议 +
   修订宪章原则六表述；不达标则如实记录维持降级；
3. **性能画像精确标定**（二期 WS3 #4 挂起项）：专用基准环境下的阈值标定；
4. **ffmpeg 负载抖动**：编码重试 + 断点续跑的运维化处置（根因属环境）；
5. **`MAX_TOKENS`/`JUDGE_MAX_TOKENS` 入形态配置**（016 遗留）；
6. **角色 × 档案成本分解在报告层展开**（016 遗留）。

### 3.2 Out of Scope（三期不做）

- **开发 Agent 自动进化**：信号噪声最大环节，维持人工主导（技术方案 §2.2 警示，三期不翻案）；
- 底层生成模型权重任何形式的微调/进化（永久红线）；
- 多租户/商业化产品化（内部生产系统定位不变）；
- 公网部署与在线服务化（前端保持只读 + 本机语义）。

## 4. 里程碑与验收（12 周，对齐技术方案月 7~9）

| 周 | 交付 | 验收门禁 |
| --- | --- | --- |
| 1~3 | WS3 治理转正：影子期运行与误入率标定；部署自动化 `auto` 模式开启（若标定通过）；遗留 5/6 收口 | 影子期 ≥2 周数据齐备；误入率可重算；`auto` 开启有证据支撑 |
| 3~5 | **G1 开发 Agent 降级接入** | 禁止自动进化三重机检；回放对比报告可产出 |
| 5~8 | **G3 真实渠道与账单对账**（先接 LLM 与一个媒体渠道） | 真实渠道连续运行 ≥1 周；账单差异可解释；两维价目可表达 |
| 8~11 | **G2 电影长片全链路**（在真实渠道上跑通） | 七环节全链路样片包 + 成本账目 + 性能达标 |
| 9~12 | **G4 短剧真实回流** + **G5 形态插件验证** | 回流 ≥2 周；新形态零代码接入（静态断言） |
| 12 | 三期收口 | 三期交付总览发布 |

全程常驻门禁不变：对抗测试（合并阻塞）、无偏性（发布阻塞）、Immutable 审计与成本回归（每日）、
覆盖率 ≥85%（含 web）。**新增门禁**：真实渠道调用的**预算与账单差异告警**（见 G3）。

## 6. 宪章修订计划（1.1.0 → 1.2.0，MINOR）

按治理规则，以下两条以单独 PR 走修订流程，**先于**对应特性动工：

1. **原则三扩充**：从"昂贵动作仅限线上探索"扩为"**真实渠道调用必须受预算门禁与账单对账双重约束**"
   （G3 前置：真实花费需有可比对的账单证据链，而非仅网关记账）；
2. **原则六补充**：明确"剧本/开发 Agent 的升级决议"须以 012 判据材料 + 010 信度数据为依据，
   并规定决议的留痕方式（升级=新特性；维持=记录未达标原因）。

原则一、二、四、五不动。

## 7. 风险登记册（三期增量）

| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| 真实渠道花费失控 | 高 | 预算门禁按环节分档 + 每日账单对账告警 + 首次接入先最小规模（二期已验证的 `--round` 思路） |
| 厂商 API 与协议假设不符 | 高 | 三期首批即做协议校准（G3）；适配器双实现 + 契约套件已在位；真实调用暴露的问题优先修（二期实证有效） |
| 长片周期长导致链路验证慢 | 中 | 里程碑用"最小可行长片"（按形态配置缩档但不改链路）；真实作品与排练分离 |
| 真实投放的合规（版权/肖像/广告法） | 高 | 宣发合规门禁已在位（敏感词/规格）；版权链需业务侧决策，技术侧记录素材来源审计链 |
| 影子期数据不足或误入率不达标 | 中 | 如实记录并延长影子期；`auto` 不开启，人工审批继续 |
| 剧本 Agent 升级判据不达标 | 中 | 如实记录（诚实边界），维持降级模式；判据材料持续积累 |
| 多形态并行导致 core 被污染 | 中 | 静态断言（零形态分支）+ 形态插件契约测试（G5） |

## 8. 团队与预算

沿用二期配置（8~10 人），新增要求：**运营侧必须有人对接真实渠道**（凭证、预算、平台合规），
否则 G3/G4 无法推进。真实渠道预算按环节分档单列，首次接入按最小规模起步（参考二期真实
LLM 验证：单轮真实花费 $0.042，全链路扩规模前先按此量级验证协议与计费）。
