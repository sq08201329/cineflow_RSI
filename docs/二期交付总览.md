**统一模式**（六个 Agent 一致）：适配器双实现（确定性模拟 + 真实 API 实现）跑同一套
契约套件；两段式落盘（可变运营表 → 合并后一次性 INSERT）；定点归一（6 位小数）；
预算门禁（事务扣减 + 轮次幂等）；回放零生成（审计断言）；无偏性 τ≥0.95 发布阻塞。
其中**视觉/分镜/剪辑三个媒体环节的真实适配器已由骨架落地为协议实现**（接口语义钉死在

## 3. 二期新增的四个基建能力

### 3.1 跨项目发现树合并回放（011）

- 按 **(Agent, 形态)** 分组，池内树按**评估器版本集**分组（跨版本不混池）
- 跨项目匹配（结构键 + 版本集）；**得分冲突即 UNKNOWN**（保守口径，如实诊断）
- 稀释控制：**命中占比**超阈告警（树数占比作参考）；做梦启用合并池需显式开关（默认关闭）
- 同树在单项目池与合并池回放得分序列一致（"合并不改变回放语义"的可证伪断言）

### 3.2 judge 漂移自动检测（012）

- 数据源零新增（010 的分布快照/台账/信度）；**PSI 分布距离 + 分位数偏移**双维判定
- 滑动窗口基线（最近 N 周期）；首周期记基线、样本不足如实标注、升版即新基线
- 状态机 `normal → suspect → confirmed_drift | false_alarm`：**系统只写 suspect**，
  终态仅人工处置写入；分级处置（suspect 降权 0.5 / confirmed_drift 排除）
- 双信号强化告警（漂移 ∧ 信度下降）；部署证据接口对漂移状态**拒绝**

### 3.3 只读前端（013）

- `web/` 为宪章唯一目录例外：**零 import core/agents/dreaming**（静态断言）
- **只读三重机检**：路由表仅 GET / 独立只读角色 `cineflow_web`（迁移 0009，全表仅 SELECT、
  写动词 REVOKE、未来表默认只读）/ 源码静态断言无写调用与写 SQL
- 同源分层校验：有报告产物的面板逐字段一致；树/节点以 DB 为权威源
- 静态导出（断服务后纯静态服务器仍可浏览）；默认 127.0.0.1 + 可选 token

### 3.4 部署评估自动化（014）

- **证据门槛**：前置 = 无偏性验收通过；三要件 = reward 超现部署 + validation 不跌出前 20%
  + judge 漂移通过；**缺证据即拦截**；禁止名单（009 的 screenplay/dev）优先级最高
- **影子模式**：判定照跑但不切指针；影子期 ≥2 周 + 候选数双下限才可开启 auto；
  对照报告含"系统会放行但人工拒绝"的差异分类
- **渐进抽检**：前 N 次（默认 5）全量复核 → 之后按比例；**否决回滚三件事同时生效**
  （指针回滚 + 模式回 manual + 标记重标定）
- **指针一致性检测**：指针与留痕不一致即拒绝 + 告警（防外部绕过）；误入率可重算

## 6. 跨特性关键设计决策（二期新增，复用价值最高的八条）

1. **结构键匹配语义**（006→009→011）：回放匹配键只含**策略可复现的结构键**，不含生成产物
   摘要——否则新策略必然 UNKNOWN；这是池化与对比的共同基础。
2. **冲突即 UNKNOWN**（011）：跨项目同结构同版本但得分不同 → 不得分 + 诊断。得分不一致
   说明"可复现"假设不成立，保守口径优于取均值。
3. **系统只写 suspect**（012）：监控系统只记录"不确定"，终态判定权完全归人——把原则六
   变成可机检的写入权限约束。
4. **只读纪律的三重证明**（013）：路由表 + 数据库角色 + 源码静态断言；"不存在 import"
   比"承诺不写"更硬。
5. **缺证据即拦截**（014）：门槛判定里"证据不足"与"要件不满足"行为一致、理由分开——
   宁可拦截，且理由可归因。
6. **否决回滚三件事一个事务**（014）：指针回滚 + 模式回 manual + 重标定标记；任一失败显式
   报错并保持人工（绝不停留在不确定状态）。
7. **形态差异只在配置**（015）：短剧配置必须过**全部加载器**——若某处需要代码分支，
   配置完整性测试立刻暴露；这是"零代码切换"的可证伪形式。
8. **执行器与业务链分层**（015）：通用 DAG 入 core（零业务概念、静态断言），链定义与交接
   契约在业务侧；交接用**双向快照**锁定（治"各自单测全绿、串起来失败"）。

## 7. 诚实边界：真实 vs 模拟（二期更新）

| 环节 | 二期实现 | 接入真实的方式 |
| --- | --- | --- |
| LLM 调用 | Mock 后端（确定性、零成本）+ **真实协议实现**（OpenAI 兼容 chat/completions，usage 以响应为准、网关按价目表折算） | 配 `OPENAI_BASE_URL` / `OPENAI_API_KEY` |
| TTS / 音乐生成 | 确定性模拟（种子 → 程序化音频 → wav 逐字节复现）+ **真实协议实现**（wav 工件 + 声学属性元数据，本地 stub 已验证） | `SOUND_TTS_*` / `SOUND_SFX_*` / `SOUND_MUSIC_*` |
| 视频生成 / 渲染 | 确定性模拟（分镜卡帧/程序化片段，单线程确定性编码）+ **真实协议实现**（视觉/分镜/剪辑，本地 stub 已验证） | `VISUAL_GEN_*` / `STORYBOARD_RENDER_*` / `EDIT_RENDER_*`（接入真实厂商时按厂商 API 校准路径/鉴权/字段） |
| 广告投放 | 确定性模拟平台 + **真实协议实现**（campaign/metrics/pause；指标未就绪如实报错、越界即拒） | 平台凭证（`PROMO_PLATFORM_*`） |
| **试水作品样片** | **全模拟链路**（可复现排练） | B/C 路径：真实生成凭证 + 投放账号（见 `docs/二期升级路径-真实生成与投放.md`） |
| 影子期（2 周）与误入率标定 | 机制、计时、对照报告已交付 | **真实运行与标定结论属运营** |
| 抽检执行 | CLI 通道 + 留痕 | 人工操作（Web 看板只读，不开放抽检） |
| 真实在线轨迹 / 平台回流 | 录制夹具 + promo 回流管道 | 运营节奏（无代码变更） |

**原则不变**：模拟不等于假装——所有模拟实现都在契约套件的同等约束下，切换真实渠道是
配置动作而非重写（015 升级落地：后端选择由形态配置 `pilot` 段驱动，唯一装配点
`agents.pilot.backends::build_backends`，CLI 提供 `--backend` / `--llm-backend`；声明 `http`
而凭证缺失 = 装配期显式失败、零落树零扣费，**不静默回落模拟**）；**模拟产物必须标注
"模拟生成"**（015 样片包已强制）。**LLM 接入（功能 016）**：模型档案（端点/凭证变量名/价目）与角色路由**全配置化**，业务代码零厂商
字面量（静态断言）；价目随 `config_snapshot["llm_profiles"]` 冻结（改价不漂移，机检可证伪）；
凭证只按档案声明读取（环境里无关的 `OPENAI_API_KEY` 不再造成假阳性），核查器/冒烟器/升级清单
三者与配置同源（`tests/unit/test_upgrade_manifest_lock.py` 双向锁）。

**例外（如实登记）**：**全部适配器族**（视觉/分镜/声音×3/剪辑/宣发/LLM）已是
**协议实现**（接口语义钉死在 `core/platform_http.py`；62 条 stub 端到端 + 契约套件真实分支
实跑 `CINEFLOW_CONTRACT_STUB=1 uv run pytest tests/contract` 309 条通过，见
`tests/integration/test_http_real_stub.py`），但**"能连本地 stub"不等于"B/C 路径已验证"**——
真实厂商的路径/鉴权/字段与真实计费未跑过；B/C 未交付的登记不变。
另有一处**如实拒绝**（1.4.0）：声音响度标定基于模拟合成器口径，切 `sound: http` 时
`build_sound_plans` 直接拒绝（零生成零扣费）并给出两条替代做法（见
`docs/二期升级路径-真实生成与投放.md` §五）。
