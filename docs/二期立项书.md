## 2. 二期定位与目标

**定位**：把做梦闭环从"两个先锋环节"铺开为"生产链主体"，同时补齐一期冻结的工程能力，
并以一部短剧形态试水作品作为端到端业务验证（短剧 = 高频练兵场，校准结论后续迁移回电影线）。

**北极星指标（承接技术方案 §5.3，阶段二目标值）**

| 指标 | 一期出口 | 二期目标 |
| --- | --- | --- |
| 进化增益 | 5 轮无塌缩（demo 规模） | 宣发/视觉在真实运营节奏下持续 >1；新接入 Agent 各自产出首轮进化曲线 |
| 算力杠杆比 | 成本入账体系就绪 | ≥10× 有真实对账数据支撑（阶段三 ≥50×） |
| 评估器信度 | 一致性验收机制就绪 | 外环周校准运转 ≥8 周，核心环节内环得分与人评相关 ≥0.6 或诚实记录未达 |
| 单项目边际成本 | — | 试水作品全流程成本入账，产出首份边际成本对比 |
